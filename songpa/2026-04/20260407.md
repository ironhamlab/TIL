### 1. HTML
: 웹 페이지를 작성하는데 사용되는 표준 마크업(태그) 언어. 웹 페이지의 구조와 컨텐츠를 정의하는데 사용.

#### (1) Text and List

* hr : 줄바꿈
* br : 한 줄 공백
* p : 문단 구분 태그
* ⭐**pre** : 작성한 모양 그대로 보여주는 문단 구분 태그 (주로 코드 표현 시 사용)

</br>

* b : 단순 굵은 글씨
* ⭐**strong** : 중요한 내용으로 의미 부여한 굵은 글씨
* i : 단순 이탤릭체
* ⭐**em** : 강조하고 싶은 내용으로 의미 부여한 이탤릭체
* mark : 형광펜 표시
* del : 가운데 줄 표시

</br>

* ul : 순서가 중요하지 않은 리스트 (Unordered List)
* ol : 순서가 중요한 리스트 (Ordered List)
* li : 각 리스트 목록 (ul / ol 내부에 사용)
* ⭐꿀팁 | **ul>li*3** => ul 안에 li 3개 들어간 형식이 나옴!

</br>

---
#### (2) Table and Media

=> tr 먼저, td 나중에. 쪼개는 걸 먼저, 병합을 나중에.

* table : 전체 표를 감싸는 태그
* caption : 설명
* thead : 표의 제목 행
* tr : 표의 한 '행'을 의미 (Table Row) 
* th : 제목 셀. 자동으로 굵게 표시됨. (Table Header)
* tbody : 표의 일반 행
* td : 일반 셀. (Table Data)

</br>

* rowspan="2" 뜻 : 이 칸은 아래 칸과 합쳐서 '2줄' 차지
* colspan="2" 뜻 : 이 칸은 오른쪽 칸과 합쳐서 '2칸' 차지

</br>

* img : 이미지 넣기, alt의 경우 접근성이나 이미지 불러오기 실패 시 매우 중요하므로 꼭 넣어주어야 함. width, height 등으로 크기 조절 가능

* ⭐**figure, figcaption** : 이미지와 설명을 의미적으로 묶어주는 태그

* audio : 오디오 넣기. controls 함께 넣어줘야 오디오 컨트롤러 뜸!

* video : 비디오 넣기. controls 함께 넣어줘야 비디오 컨트롤러 뜸!

</br>

---
#### (3) Link and Form

* a : 링크. target="_blank" 함께 설정해주면 새 탭으로 이동 됨!
* 페이지 내부의 특정 위치로 이동하고 싶다면, id를 지정해서 href에 해당 아이디를 a href="#id" 형식으로 적어주면 됨

</br>

* form : 사용자가 입력한 데이터를 서버로 보내는 창구 역할
* action -> 데이터를 처리할 서버 주소, 없으면 # 으로 두기
* method -> 데이터 전송 방식 (ex. post)
* fieldset : 폼 요소를 그룹화하여 테두리를 그려줌
* legend : fieldset의 제목이 됨

</br>

* label : 설명 
* input : 인풋 (text, password, radio, checkbox 4가지 type 실습해봄!)
* label for 와 input id를 연결하면 사용성 향상(label을 클릭해도 input에 포커스 됨)
* placeholder -> 인풋에 대한 설명을 줌
* name -> 서버에서 얘를 받아올 때 데이터에 대한 키값으로 쓰임
* radio type의 경우 하나만 선택 가능. 주의할 점은, name이 같은 것 끼리 중에서만 하나 선택됨. name으로 묶어주지 않으면 개별 요소가 되어서 모두 선택 가능
* checkbox type의 경우 여러개 선택 가능

</br>

* textarea : 긴 글을 적을 수 있음. textarea id와 label for 연결하면 사용성 향상. rows, placeholder 등 설정 가능. rows="5" => 5줄 입력 가능한 여백

* button : 버튼 (submit, reset 2가지 type 실습해봄, default는 submit)

</br>

---
#### (4) div, span, semantic

* div : 블럭 레벨 요소, 영역을 나눈다는 뜻(division). 한 '줄'을 통째로 차지
* span : 인라인 요소, 특정 범위를 지정한다는 뜻. '콘텐츠 크기만큼'의 공간만 차지

</br>

* header : 페이지나 특정 구역의 '머리말'을 의미 (로고, 제목, 메뉴)
* main : 주요 콘텐츠를 포함하는 영역
* section : 관련 콘텐츠 그룹. 일반적으로 제목(h1~h6)으로 시작함
* footer : 바닥글 영역

</br>

### 2. CSS
: Cascading Style Sheets, 웹 페이지의 스타일과 디자인을 정의하는 스타일시트 언어.

</br>

#### 💡사용법

0. **CSS의 기본 문법**
```
    선택자 {
        속성: 값;
        속성: 값;
    }
```

</br>

1. **내부 스타일 시트 방식**
    
    : HTML 문서의 `<head>`태그 안의 `<style>` 태그 내에 작성 된 CSS 코드를 적용
    
2. **외부 스타일 시트 방식**
    
    : <link rel=”stylesheet” href=” css 외부 파일 경로”>를 통해 CSS 파일(CSS 확장자를 가짐)에 작성된 CSS 코드를 적용
    
3. **인라인 방식**
    
    : HTML 요소의 style 속성(attribute)에 CSS 코드를 적용

</br>

---

#### (1) 선택자

* 태그 선택자 : HTML 태그 이름을 그대로 사용
* 클래스 선택자: 점(.)으로 시작. 여러 요소에 '별명'을 붙여 그룹으로 꾸밀 때 사용
* 아이디 선택자: 샵(#)으로 시작. 페이지에서 '단 하나뿐인' 요소에 '이름표'를 붙일 때 사용
* 후손 선택자: 띄어쓰기로 구분. 특정 요소 '안에 있는' 모든 후손을 선택
* 자손 선택자: > 기호로 구분. 특정 요소의 '바로 아래 자식'만 선택

</br>

---

#### (2) 글자와 상자
* 구글 폰트 > head에 **링크** 붙여넣고, style 적용하고자하는 곳에 **font-family** 로 적용하기

```CSS
h1 {
    color: gray; /* 색상 코드. 16진수, rgb, rgba 등으로 표현 가능*/
    font-size: 40px;
    font-weight: lighter;
    text-align: center; /* 텍스트 정렬 */
}

.box {
    background-color: seashell;

    width: 300px;   /* 너비 */
    height: 150px;  /* 높이 */

    padding: 20px;  /* 테두리 안쪽 여백 */

    border: 2px dashed green;

    margin: 30px;   /* 테두리 바깥 여백 (다른 요소와의 간격) */
}

.rounded-box {
    background-color: blueviolet;
    color: white;
    padding: 10px;
    margin: 10px;
    border-radius: 15px;    /* 모서리를 둥글게 */
    box-shadow: 10px 10px 15px fuchsia;
}
```

#### (3) 레이아웃

**1. Flexbox로 배치하기 (가장 많이 사용!)**
```CSS
.flex-container {
    display: flex;
    justify-content: space-between;
    align-items: center;    /* 교차축(세로) 방향으로 아이템을 중앙 정렬 */
    height: 150px;
}
```

</br>

**2. Grid로 배치하기**
```CSS
.grid-container {
    display: grid;
    /* 사용 가능한 공간을 1:1:1 비율로 나눈 3개의 열을 만듦 */
    grid-template-columns: 1fr 1fr 1fr;
    gap: 10px;
}

.grid-container .item:first-child {
    grid-column: 1 / 3;
}
```

</br>

**3. Position으로 배치하기**
```CSS
.position-container {
    position: relative;
    height: 200px;
}

.position-container .blue {
    position: absolute;
    top: 50px;
    left: 50px;
    width: 100px;
    height: 100px;
}
```

</br>

#### (4) 인터랙션
```CSS
.button {
    display: inline-block;
    padding: 15px 30px;
    background-color: aqua;
    margin: 20px;
    color: black;
    text-decoration: none;
    border-radius: 10px;
    transition: all 0.3s ease;
}

/* 1. Hover: 마우스 커서를 올렸을 때의 상태를 선택 */
.button:hover {
    background-color: blue;
    color: white;
    /* transform : 요소의 모양 변형 */
    transform: translateY(-5px);
    box-shadow: 0 5px 10px black;
}

/* 2. Active: 요소를 클릭하고 있는 동안의 상태 선택 */
.button:active {
    transform: translateY(-2px);
}
```
