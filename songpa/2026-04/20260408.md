## 1. JS의 개요

### 1-1. JS의 역사

- 1996년 처음 개발되었다.
- 표준화 전 크로스 브라우징 이슈
- ECMAScript 로 명명되었다.
- 우리가 다룰 것은 ES6

### 1-2. JS의 성장

- Ajax → 원래는 무조건 하얀 화면이었다가 로딩됐는데, 이제 부드러운 화면 전환 가능

### 1-3. JS의 특징

- 웹 브라우저에서 동작하는 유일한 프로그래밍 언어

- 프로토타입 기반의 객체지향 언어

## 2. 변수
### 2-1. 데이터타입
#### 2-1-1. 키워드
* 변수
    * 변수는 데이터를 저장할 때 쓰이는 '이름이 붙은 저장소'이다.
    * 변수를 생성할 때 우리는 변수를 선언한다고 표현한다.

    </br>

* **키워드 변수명;**
    * 키워드 : 변수의 접근 범위를 지정
    * 변수명 : 변수를 부를 이름 설정.

    </br>

* **키워드 종류**
* **var**: ES5 까지 사용했던 유일한 키워드
* **let**: 값을 변경할 수 있는 변수 선언
* **const** : 재할당 금지
    * const 키워드로 선언한 변수는 반드시 선언과 동시에 초기화 해야 하다

    </br>

 * **변수 선언 규칙과 스타일**
     - 변수 이름은 알파벳, 숫자, _, $만 사용할 수 있다.
     - 변수 이름은 숫자로 시작할 수 없다.
     - 카멜케이스(camelCase)를 사용하는 것이 일반적이다.
     - 예약어 사용 금지(예시. if, for 등)
     - 대소문자 구분: 변수 이름에서 대소문자를 구분한다. A, a는 다른 변수이다.
     - 의미 있는 이름 사용: 변수 이름은 그 변수의 역할이나 내용을 명확하게 나타내는 것이 좋다.

</br>

#### 2-1-2. 원시 데이터 타입(primitive types)
: 원시 타입은 변경 불가능한 값들이며, 자주 사용되는 원시 타입으로는 숫자(number), 문자열(string), 불린(boolean), null, undefined 등이 있다.


**1. 숫자(number)**
* 숫자 타입은 모두 실수로 처리된다.

**2. 문자열**
* 작은 따옴표(''), 큰 따옴표(""), 또는 백틱(``)으로 텍스트를 감싼다.

**3. 불린(boolean)**
* 논리적 참, 거짓을 나타내는 true와 false 뿐이다.

**4. null**
* 명시적으로 값이 없음을 의도적으로 명시할 때 사용

**5. undefined**
* 변수에 값이 할당되지 않았을 때 자동으로 할당되는 값

**6. typeof**
* 데이터 타입을 확인할 때 사용

</br>

#### 2-1-3. 템플릿 리터럴
* ES6부터 도입 된 멀티라인 문자열, 표현식 삽입 등의 편리한 문자열 처리 기능을 제공하는 문자열 표기법

* 작은 따옴표, 큰 따옴표 대신 백틱(``)을 사용해 표현한다. 

* 일반 문자열 내에서는 줄바꿈이 허용되지 않아 이스케이프 문자를 사용해야하는 반면, 백틱을 사용하면 줄바꿈과 공백이 있는 그대로 적용됨.

* 표현식 삽입 : ${}

```js
let str = '안녕하세요.
반갑습니다.';

let str = '안녕하세요. \n반갑습니다.'
console.log(str);

// 백틱을 사용하면 줄바꿈과 공백이 있는 그대로 적용됨
let multiline = `안녕하세요.
반갑습니다.`
console.log(multiline);

let lastName = '홍';
let firstName = '길동';

console.log('제 이름은 ' + lastName + firstName + '입니다');

// 표현식 삽입 : ${}
console.log(`제 이름은 ${lastName + firstName}입니다.`)
console.log(`제 이름은 ${lastName}${firstName}입니다.`)
```

### 2-2. 타입 변환
#### 2-2-1. 암묵적 타입 변환
 * 자바스크립트 엔진에 의해 암묵적으로 타입이 자동 변환 되는 것
 * 타입 변환 된 결과를 예측할 수 있어야 오류를 방지할 수 있다.

</br>

**1. 문자열 타입으로 변환**

* 문자열 연결 연산자로 동작
* 문자열 타입이 아닌 피연산자를 문자열 타입으로 암묵적 변환
```js
console.log(10 + '20');     //1020

console.log(1+ '');
console.log(NaN + '');      //NaN : Not a Number
console.log(undefined + '');
console.log(null + '');
```

</br>

**2. 숫자 타입으로 변환**

```js
console.log(10 - '5');  // 5
console.log(10 * '5');  // 50
console.log(10 / '5');  // 2
console.log(10 % '3');  // 1
console.log(10 % 'JavaScript');  // NaN

console.log(10 > '5');  // true
```

* '+' 단항 연산자는 피연산자가 숫자 타입의 값이 아니면 숫자 타입으로 암묵적 타입 변환 수행
```js
console.log(+'');       // 0
console.log(+'5');      // 5
console.log(+true);     // 1
console.log(+false);    // 0
```

</br>

**3. 불리언 타입으로 변환**

자바스크립트 엔진은 불리언 타입이 아닌 값을 Truthy 값(참으로 평가되는 값) 또는 Falsy 값(거짓으로 평가되는 값)으로 구분한다.

* **Falsy한 값 (false로 평가되는 값)**
    * false
    * 0 (숫자 0)
    * '' (빈 문자열)
    * null
    * undefined
    * NaN (Not a Number)

</br>
</br>

#### 2-2-2. 명시적 타입 변환
 * 개발자의 의도에 따라 값의 타입을 변환하는 것


**1. 문자열 타입으로 변환**

(1) String 생성자 함수를 new 연산자 없이 호출
=> 어떤 값이 들어올지 모를 때 가장 안전하게 쓸 수 있는 방법
```js
console.log(String(10));    // "10"
console.log(String(true));  // "true"
console.log(String(null));  // "null"
```

(2) toString 메서드 사용
```js
console.log((10).toString());   //"10"
console.log((null).toString()); // TypeError
```

</br>

**2. 숫자 타입으로 변환**

(1) Number 생성자 함수를 new 연산자 없이 호출(완벽히 숫자일 때만 가능)
```js
console.log(Number('10.01'));    // 10.01
console.log(Number('10원'));      // NaN
console.log(Number(true));        // 1
console.log(Number(false));       // 0
```

(2) parseInt, parseFloat 함수 이용 (문자열 -> 숫자만 가능)
```js
console.log(parseInt('10.01'));     // 10
console.log(parseFloat('10.01'));   // 10.01
```

</br>

**3. 논리 타입으로 변환**

(1) boolean 생성자 함수를 new 연산자 없이 호출하는 방법
 * Falsy 6총사 (false, undefined, null, 0, '', NaN)는 false로,
 * 나머지는 true로 바꿔주는 방법
```js
console.log(Boolean('JS'));     // true
console.log(Boolean(0));        // false
console.log(Boolean(NaN));    // false
```

(2) ! 부정 논리 연산자를 두 번 사용하는 방법
```js
console.log(!true);     // false

console.log(!!'');        // false
console.log(!!1);        // true
console.log(!!0);        // false
```

</br>

## 3. 연산자
### 3-1. 연산자


**1. 산술 연산자**
```js
let a = 10;
let b = 3;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);      // 나눗셈
console.log(a % b);    // 나머지
console.log(a ** b);   // 거듭제곱
```

**2. 할당 연산자**
```js
let c = 5;
c += 3;
console.log(c);     // 8

c -= 2;
console.log(c);     // 6
```

**3. 증감 연산자**
```js
let d = 5;
console.log(d++);   // 후위 증가
console.log(++d);   // 전위 증가
console.log(d--);   // 후위 감소
console.log(--d);   // 전위 감소
```

</br>
</br>

### 3-2. 비교 연산자
 * 비교 연산자는 좌항과 우항의 비교 연산자를 비교한 다음 그 결과를 불리언 값으로 반환
 * if문이나 for문 같은 제어문의 조건식에서 주로 사용한다.

```js
let x = 10;
let y = 20;
```

</br>

**1. 동등 연산자(==, !=)**: 먼저 암묵적 타입 변환을 통해 타입을 일치시킨 후 같은 값인지 비교.
```js
console.log(x == y);    // == : 값이 같으면 true (출력: false)
console.log(x != y);    // != : 값이 다르면 true
console.log(x == '10');     // 암묵적 타입 변환을 했기 때문에 true 반환
```

</br>

**2. 일치 연산자(=\==, !==)**: 타입과 값이 모두 일치하는지 비교
```js
console.log(x === 10);    // ===: 값과 타입이 같으면 true
console.log(x === '10');  // 타입이 다르므로 false
```

</br>

**3. 대소 비교 연산자**
```js
console.log(x > y);
console.log(x <= y);
```

</br>

**※ 문자열도 크기 비교 가능, 유니코드 순서로 비교한다.**
* 컴퓨터 세상에서는 모든 대문자가 소문자보다 앞에 온다.
```js
console.log(`'cat' >= 'Zoo' : ${'cat' >= 'Zoo'}`);
//'cat' > = 'Zoo' : true
```

</br>
</br>

### 3-3. 논리 연산자
 * 논리 연산자는 여러 조건을 결합하여 하나의 논리적 결과를 도출한다.
 * AND, OR, NOT 연산자가 있다.

```js
const a = true;
const b = false;
```
**1. 논리 AND (&&)**: 모두 true일 때만 true 반환
```js
console.log(a && a);
console.log(a && b);
```

</br>

**2. 논리 OR(||)**: 둘 중 하나만 true여도 true 반환
```js
console.log(a || a);
```

</br>

**3. 논리 NOT (!)**: true이면 false로, false이면 true로 반전
```js
console.log(!a);
console.log(!b);
```

</br>

**※ 단축평가**
 * 표현식 평가하는 도중 평가 결과가 확정된 경우 나머지 평가 과정을 생략하는 것
```js
console.log('apple' || 'banana');   // apple
console.log(false || 'banana')      // banana             

console.log(false && 'banana')    // false
```

</br>

* 단축평가를 이용한 Null 체크!
```js
let obj  = null;

// let objValue = obj.value;   //TypeError: Cannot read properties of null (reading 'value')

let objValue = obj && obj.value;
```

</br>

* **단축 평가의 치명적 단점**
    * 0이나 빈 문자열('')처럼 나름 의미가 있는 값들까지 '문제(Falsy)'로 취급

</br>
</br>

**※ Optional Chaining (옵셔널 체이닝)**
* obj가 null 또는 undefined 인 경우 undefined 반환
* obj가 다른 Falsy한 값(0, '') 인 경우 그대로 0 또는 '' 반환

```js
const obj1 = null;
const objValue1 = obj1?.value;
```

</br>
</br>

**※ null 병합 연산자**
 * 좌항의 피연산자가  null 또는 undefined인 경우 우항의 피연산자 반환,
 * 그렇지 않으면 좌항의 피연산자를 반환한다.

```js
let test = null ?? '기본 값';
console.log(test);   // 기본 값

let value = 0 ?? '기본 값';
console.log(value);  // 0
```

</br>
</br>

### 3-4. 삼항 연산자
 * 삼항 연산자는 조건식에 따라 두 값 중 하나를 선택하는 연산자이다.
 * 조건 ? 값1 : 값2
 * 조건이 true 일 경우 값1, false일 경우 값2 선택

</br>

**1. 삼항 연산자 사용**
```js
let age = 20;
let result = (age >= 20) ?  "성인" : "미성년자";
console.log(result);   // 성인
```

</br>

**2. 중첩된 삼항 연산자**
```js
let score = 85;
let grade = (score >= 90) ? "A" :
                (score >= 80) ? "B" : 
                (score >= 70) ? "C" : "D";
console.log(grade);   // B
```

## 4. 조건문과 반복문

### 4-1. 조건문 (if문, switch문)

#### 4-1-1. if-else문
```
if (조건식) {
         // 조건식이 true인 경우 실행 구문
} else {
         // 조건식이 false인 경우 실행 구문
}
```

```js
let temperature = 5;

if (temperature < 10) {
    console.log("오늘은 춥습니다.")
} else {
    console.log("오늘은 날씨가 괜찮습니다. ")
}

//오늘은 춥습니다.
```

</br>

#### 4-1-2. if-else if-else문
 * 여러 조건을 처리할 때 쓴다.

```js
let score = 85;

if (score >= 90) {
    console.log("매우 우수")
} else if (score >= 70) {
    console.log("양호")
} else if (score >= 50) {
    console.log("보통")
} else {
    console.log("부족")
}

//양호
```

#### 4-1-3. switch문
 * 하나의 변수에 대해 여러 경우를 처리

```js
let fruit = '바나나';

switch (fruit) {
    case '사과':
        console.log('선택한 과일은 사과입니다.');
        break;
    case '바나나':
        console.log('선택한 과일은 바나나입니다.');
        break;
    default:
        console.log('알 수 없는 과일입니다.');
}

//선택한 과일은 바나나입니다.
```

</br>
</br>

### 4-2. 반복문 (for문, while문)
#### 4-2-1. for문
* 명확한 반복 횟수를 지정하여 코드 실행
```
for (초기화;조건식;증감식) {
     // 반복 실행할 코드
}
```

```js
for (let i = 1; i <=5; i++) {
    console.log(`반복 횟수: ${i}`);
}

/*
반복 횟수: 1
반복 횟수: 2
반복 횟수: 3
반복 횟수: 4
반복 횟수: 5
*/
```
```js
// 1부터 10까지의 숫자 중 짝수만 출력
for (let i = 1; i <= 10; i++) {
    if (i % 2 === 0) {
        console.log(i);
    }
}

/*
2
4
6
8
10
*/
```
