## 1. 클래스

* ES6에서 도입된 객체를 생성하기 위한 새로운 설계도 양식이다.
* 기존의 생성자 함수보다 훨씬 더 명확하고 체계적으로 객체를 설계할 수 있다.

</br>

```js
// 클래스 선언
class Student {
    // new 키워드로 객체를 만들 때, 딱 한 번 실행되는 함수
    constructor(name, group) {
        this.name = name;
        this.group = group;
    }

    //메서드: 이 클래스로 만들어진 모든 객체가 공유하는 기능
    //이 함수는 객체마다 복사되지 않고, Student.prototype에 저장된다.
    introduce() {
        console.log(`안녕하세요! ${this.group}반 ${this.name}입니다.`);
    }
}

const studentA = new Student('홍길동', 'A');
// const student = Student('홍길동', 'A');  // new 키워드 없으면 에러 발생!
const studentB = new Student('유관순', 'B');
```

</br>

* 모든 인스턴스가 같은 함수를 쓴다 -> 메모리 절약, 성능 효율
```js
console.log(studentA.introduce === studentB.introduce);
```

## 2. 화살표 함수

* ES6에서 도입된, 함수를 간결하게 표현하는 문법이다.
* 단순히 문법만 짧아진 것이 아니라, 'this'를 다루는 방식도 바뀌었다.

</br>

* 기본 변환 function 키워드를 '=>' 로 바꿈 
```js
const message = function() { return 'hello world!'; };
const arrowMsg1 = () => { return 'hello world!'; };
console.log(arrowMsg1());
```

</br>

* 본문이 return 한줄이면, 중괄호{}와 return 동시 생략 가능!
```js
const arrowMsg2 = () => 'hello simple arrow!';
```

</br>

* 매개변수가 하나일 때, 소괄호() 생략 가능
```js
const power = function(x) { return x * x; };
const arrowPower = x => x * x;
```

</br>

* 매개변수가 없거나, 두 개 이상이면 소괄호() 필수
```js
const greet = () => 'hello!'
const sum = (a, b) => a + b;
```

</br>

* **(주의!) 객체 리터럴을 반환할 때는 소괄호()로 감싸야 한다.**
* 감싸지 않으면 함수 몸체의 중괄호{}로 오해한다.

```js
const createUser =  (id, name) => ({ id, name });
```

</br>

* 고차함수와 쓸 때 위력이 극대화 된다.
```js
const numbers = [1, 2, 3, 4, 5];
// const mappedNumbers = numbers.map(function(val) { return val * 10;});
const mappedNumbers = numbers.map( val => val * 10 );

console.log(mappedNumbers);
// [ 10, 20, 30, 40, 50 ]
```

</br>

* 하지만 화살표 함수는 자신만의 'this'를 가지지 않고, 바깥 스코프의 'this'를 그대로 쓴다.

```js
        // 일반 함수를 사용한 경우
        // this.titles.forEach(function(title) {
        //     console.log(this.store + ': ' + title);
        // })

        // forEach의 콜백함수 내 this.store의 this는 전역함수, 즉 windows 혹은 global을 가리킨다.

theater.showMovieList();
```

## 3. 이터러블

* '순회 가능한'데이터 컬렉션을 위한 통일된 규약(프로토콜)입니다.
* 배열, 문자열, NodeList, Map, Set 등은 모두 '이터러블'이다.

</br>

* 이터러블의 가장 큰 특징은 'for...of' 반복문을 사용할 수 있다는 것이다.

```js
const array = ['사과', '바나나', '딸기'];

for (const item of array) {
    console.log(item);
}
/*
사과
바나나
딸기
*/


const string = '안녕하세요';

for (const char of string) {
    console.log(char);
}
/*
안
녕
하
세
요
*/
```

</br></br>

* 이터러블: '순회 가능한' 규약을 따르는 객체.(for...of 가능)
* 유사 배열: 인덱스와 length 프로퍼티가 있어서 배열처럼 '생긴 객체'
* Array.from()을 사용하여 '진짜 배열'로 변환할 수 있다.

</br>

* 대표적인 '유사 배열 객체'
```js
const arrayLike = {
    0: '배열인듯',
    1: '배열아닌',
    2: '유사 배열 객체',
    length: 3
};

// for(const item of arrayLike) { 
//     console.log(item);
// }
// TypeError: arrayLike is not iterable

// Array.from()을 사용하여 '진짜 배열'로 변환할 수 있다.
const realArray = Array.from(arrayLike);
console.log(realArray);
//[ '배열인듯', '배열아닌', '유사 배열 객체' ]
```

</br></br>

**※ (참고)변환과 동시에 map처럼 활용하기**
* 1부터 5까지의 숫자를 가진 배열 만들기
* 실무에서 초기 데이터를 만들 때 사용됨

```js

const fiveArray1 = [0, 0, 0, 0, 0].map((_, i, array) => i + 1);
```

## 4. Rest 파라미터와 Spread 문법

* 똑같이 점 세 개(...)를 사용하지만, 쓰이는 위치에 따라 정반대의 역할을 한다.
    * **Rest Parameter**: 여러 개의 값을 하나의 배열로 '모으기'
    * **Spread Syntax**: 하나의 배열을 여러 개의 값으로 '펼치기'

</br></br>

**[ Rest Parameter ]**
 * 함수의 '매개변수' 자리에 사용하여, 정해지지 않은 개수의 인수들을
 * 하나의 '배열'로 모아서 받는다.

</br>

* Rest 파라미터는 반드시 매개변수 목록의 가장 마지막에 위치해야 한다.
```js
function merge(first, ...args) {
    console.log(`첫 번째: ${first}`);
    console.log('나머지(배열):', args);

    let message = first;
    for (let arg of args) {
        message += arg;
    }

    return message;
}

console.log(merge('안녕하세요'));
/*
첫 번째: 안녕하세요
나머지(배열): []
안녕하세요
*/
console.log(merge('안녕하세요', '반갑습니다', '저는 판다 입니다.'));
/*
첫 번째: 안녕하세요
나머지(배열): [ '반갑습니다', '저는 판다 입니다.' ]
안녕하세요반갑습니다저는 판다 입니다.
*/
```

</br></br>

**[ Spread Syntax ]**
* 함수의 '인수' 자리나, 배열/객체 리터럴 안에서 사용하여
* 배열의 요소들을 개별 값의 목록으로 펼쳐준다.

```js
const numbers = [10, 20, 30];
// Math.max(10, 20, 30): 낱개의 숫자들을 인수로 받는다.
// console.log(Math.max(numbers));  // NaN 반환

// ...numbers는 [10, 20, 30]을 10, 20, 30으로 펼쳐준다.
console.log(Math.max(...numbers));
// 30
```

</br>

* 배열 리터럴에서 사용(합치기/복사)
```js
const arr1 = [1, 2, 3];
const arr2 = [4, 5, 6];

const mergedArray = [...arr1, ...arr2, 7, 8];
console.log(mergedArray);
/*
[
  1, 2, 3, 4,
  5, 6, 7, 8
]
*/
```

</br>

* 배열 '얕은 복사'
```js
const arr1Copy = [...arr1];

console.log(arr1 === arr1Copy);
// false

arr1Copy.push(4);   // 복사본 변경
console.log(arr1Copy);  //[ 1, 2, 3, 4 ]
console.log(arr1);      //[ 1, 2, 3 ]

// 값 복사(원시값)
let a = 10;
let b = a;

// 주소 복사
let c = [1, 2];
let d = c;


// 객체 리터럴에서 사용
const obj1 = { name: '판다', age: 5};
const obj2 = { job: '강사'};

const mergedObject = { ...obj1, ...obj2, location: '서울' };
console.log(mergedObject);
//{ name: '판다', age: 5, job: '강사', location: '서울' }


// 객체 '얕은 복사'
const obj1Copy = {...obj1};
obj1Copy.age = 3;   // 복사본 변경
console.log(obj1);  // 원본에 영향 없음
//{ name: '판다', age: 5 }
```

## 5. 구조 분해 할당

 * **구조 분해 할당**
 * 배열이나 객체의 속성을 분해하여 그 값을 개별 변수에 쉽게 담을 수 있게 하는 문법
```js
const nameArr = ['Panda', 'Kwon'];

// 기존 방식
// const firstName = nameArr[0];
// const lastName = nameArr[1];

// 구조 분해 할당 방식 - 배열은 '순서'가 기준
const [firstName, lastName] = nameArr;
console.log(`성: ${lastName}, 이름: ${firstName}`);
//성: Kwon, 이름: Panda


// 쉼표를 사용해 특정 요소를 건너뛸 수 있다.
const [, name] = ['kwon', 'panda'];
console.log(name);    //panda


// rest 파라미터로 나머지 요소들을 새로운 배열로 모을 수 있다.
const [leader, ...members] = ['팀장', '팀원1', '팀원2', '팀원3']
console.log(leader);    // 팀장
console.log(members);   //[ '팀원1', '팀원2', '팀원3' ]


// 기본값 설정: 할당할 값이 없을 때 사용될 기본값 지정
const [user1, user2 = '기본값'] = ['사용자1'];
console.log(user1);     //사용자1
console.log(user2);     //기본값
```

</br></br>

* **객체 구조 분해 할당**
    * 객체는 '키(key)이름'이 중요하다. 변수 이름과 같은 키를 찾아 값이 할당된다.
    * 순서는 중요하지 않다.

```js
const student = {
    name1: '판다',
    age: 5,
    major: '영화감상'
}

// 기존 방식 
// const name1 = student.name1;
// const age1 = student.age;


//  콜론(:)을 사용하면, 'name1'키의 값을 'name1'이 아닌
// 'studentName'이라는 새 변수명으로 할당 가능
const { name1: studentName, age } = student;
// console.log(`이름: ${name1}, 나이: ${age}`);
console.log(`이름: ${studentName}, 나이: ${age}`);
////이름: 판다, 나이: 5


// 기본값(=) 설정
const { name1: sName, job = '학생'} = student;
console.log(job);   //학생


// rest 파라미터로 나머지 프로퍼티들을 새로운 객체로 모을 수 있다.
const {age: studentAge, ...restInfo} = student;
console.log(restInfo);  //{ name1: '판다', major: '영화감상' }
```
</br></br>

## 1. DOM(Document Object Model)

* 브라우저 렌더링 : 브라우저는 HTML, CSS, 자바스크립트로 작성된 텍스트 문서를 파싱하여 렌더링한다.

</br>

* DOM : 브라우저 렌더링 엔진은 HTML 문서를 파싱하여 브라우저가 이해할 수 있는 자료 구조인 DOM을 생성한다.
* 'DOM'은 트리구조와 비슷한 형태로 ' DOM Tree' 라고도 부른다.

</br>

* HTML 문서를 파싱한 결과물로서 생성된 DOM은 HTML 문서의 구조와 정보 뿐만 아니라 HTML 요소와 스타일 등을 변경할 수 있는 프로그래밍 인터페이스로서 DOM API를 제공한다. 자바스크립트에서 DOM API를 사용하면 이미 생성된 DOM을 동적으로 조작할 수 있다.

</br>

* 노드(Node) : HTML 요소는 렌더링 엔진에 의해 파싱되어 DOM을 구성하는 요소 노드 객체로 변환된다. 이때 HTML 요소의 어트리뷰트는 어트리뷰트 노드로, HTML 요소의 텍스트 콘텐츠는 텍스트 노드로 변환된다.


</br></br>

### 1-1. DOM 선택자

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>DOM 요소 선택</title>
</head>
<body>
    <h1>DOM 요소 선택</h1>

    <hr>

    <h3>`querySelector`와 `querySelectorAll`</h3>
    <pre>
        CSS 선택자를 그대로 사용하여 요소를 찾는, 가장 강력하고 일관성 있는 방법입니다.
        이 두 가지만 마스터하면 사실상 모든 요소를 선택할 수 있습니다.
    </pre>

    <ul>
        <li id="apple" class="fruit red">사과</li>
        <li class="fruit">바나나</li>
        <li>딸기</li>
    </ul>

    <script>
        // querySelector: CSS 선택자에 맞는 '첫 번째 요소 하나'만 찾아온다.
        const $apple = document.querySelector('#apple');
        $apple.style.fontWeight = 'bold';

        const $firstFruit = document.querySelector('.fruit');
        console.log($firstFruit)

        // querySelectorAll: CSS 선택자에 맞는 '모든 요소'를 NodeList로 찾아온다.
        const $fruit = document.querySelectorAll('.fruit');
        console.log($fruit);

        $fruit.forEach(item => {
            item.style.border = '1px solid blue';
        })
    </script>
</body>
</html>
```
