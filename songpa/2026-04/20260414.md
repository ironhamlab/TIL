## 1. DOM
### 1-1. DOM 요소 선택

</br>

* `querySelector` : CSS 선택자에 맞는 '첫 번째 요소 하나'만 찾아온다.
* `querySelectorAll` : CSS 선택자에 맞는 '모든 요소'를 NodeList로 찾아온다.

</br>

* `getElementById` : 주어진 문자열과 일치하는 id 속성을 가진 요소를 찾고, 이를 나타내는 Element 객체를 반환한다.
* `getElementsByClassName` : 주어진 요소의 클래스 이름에 해당하는 모든 요소를 HTMLCollection 객체로 반환한다.

</br>

```html
<body>
    <h1>DOM 요소 선택</h1>

    <hr>

    <h3>`querySelector`와 `querySelectorAll`</h3>
    <pre>
        CSS 선택자를 그대로 사용하여 요소를 찾는, 가장 강력하고 일관성 있는 방법입니다.
        이 두 가지만 마스터하면 사실상 모든 요소를 선택할 수 있습니다.
    </pre>

    <ul>
        <li id="apple" class="fruit red">사과</li>
        <li class="fruit">바나나</li>
        <li>딸기</li>
    </ul>

    <script>
        // querySelector: CSS 선택자에 맞는 '첫 번째 요소 하나'만 찾아온다.
        const $apple = document.querySelector('#apple');
        $apple.style.fontWeight = 'bold';

        const $firstFruit = document.querySelector('.fruit');
        console.log($firstFruit);

        // querySelectorAll: CSS 선택자에 맞는 '모든 요소'를 NodeList로 찾아온다.
        const $fruit = document.querySelectorAll('.fruit');
        console.log($fruit);

        $fruit.forEach(item => {
            item.style.border = '1px solid blue';
        });
    </script>
    <hr>

    <pre>
        과거에는 `getElementById`, `getElementsByClassName` 등을 사용했습니다.
        이 메서드들은 `HTMLCollection`이라는 특별한 목록을 반환하는데,
        이 목록은 '살아있어서' 예기치 못한 문제를 일으킬 수 있습니다.
        </pre>

    <div class="box">
        <p class="text">첫 번째 문단</p>
        <p class="text">두 번째 문단</p>
        <p class="text">세 번째 문단</p>
    </div>

    <script>
        const $box = document.querySelector('.box');

        const $text = $box.getElementsByClassName('text')
        console.log('반복문 시작 전 길이:', $text.length);

        //for문으로 순회하여 클래스 이름 바꾸기
        for(let i = 0; i < $text.length; i++) {
            console.log(`${i}번째 반복문 시작! 현재 $text의 길이는?`, $text.length);
            // text 클래스 제거
            $text[i].classList.remove('text');
        }
        // HTMLCollection은 첫번째 반복문을 돌면서 클래스가 제거 되었을 때 실시간으로 반영되어
        // 두번째 반복문때는 세번째 문단의 인덱스가 1번 인덱스가 되어 의도치 않게 두 번째 문단 클래스 제거가 건너뛰어지게 된다.
    </script>

    <hr>

    <h3>3. 결론: 가장 안전한 방법은 '배열'로 바꾸는 것!</h3>
    <pre>
        `querySelectorAll`은 이런 문제가 없는 '고정된' `NodeList`를 반환하기 때문에 훨씬 안전합니다.
        하지만 만약 `getElementsBy...` 같은 메서드를 꼭 써야 한다면,
        가져온 목록을 **먼저 진짜 배열로 변환한 후 사용하는 것이 가장 안전합니다.**
        </pre>

    <div class="box">
        <p class="text2">첫 번째 문단</p>
        <p class="text2">두 번째 문단</p>
        <p class="text2">세 번째 문단</p>
    </div>

    <script>
        const $texts2 = document.getElementsByClassName('text2');

        // 스프레드 문법(...)을 이용해 일반 배열로 변환
        const textArray = [...$texts2]
        console.log(textArray)

        textArray.forEach(item => {
            item.classList.remove('text2');
        });
        console.log('작업 후 $text2의 길이: ', $texts2.length);     // 0, 실시간으로 비어있음
        console.log('작업 후  textArray의 길이: ', textArray.length);   // 3, 찍어둔 시점 그대로
    </script>
</body>
```

### 1-2. node-traversal
* **자식 요소 탐색**
    * `childNodes` -> 눈에 보이지 않는 텍스트 노드(줄바꿈), 주석 까지 모두 포함하여 혼란을 준다.
    * `children`: 모든 '자식 요소'들을 HTMLCollection으로 반환(텍스트 노드 제외!)
    * `firstElementChild`: 첫 번째 '자식 요소' 반환
    *  `lastElementChild`: 마지막 '자식 요소' 반환

</br>

* **부모 요소 탐색**
    * `parentNode`: 나의 '부모 요소'를 반환

</br>

* **형제 요소 탐색하기**
    * `nextElementSibling`: 나의 바로 다음 '형제 요소'를 반환
    * `previousElementSibling`: 나의 바로 이전 '형제 요소'를 반환

</br>

```html
<body>
    <h1>'HTML 가계도' 탐색하기</h1>
    <pre>
        우리는 querySelector로 특정 요소를 찾은 뒤, 그 요소를 기준으로
        가족(부모, 자식, 형제) 요소를 찾아 나갈 수 있습니다.

        이때, 눈에 보이지 않는 '공백'이나 '줄바꿈' (텍스트 노드) 때문에 겪는 혼란을 피하기 위해
        오직 '요소(Element)'만 찾아주는 프로퍼티들을 사용하는 것이 가장 좋습니다.
        </pre>

    <ul id="family">
        <!-- 이 주석과 줄바꿈도 노드입니다! -->
        <li id="me">나 (기준)</li>
        <li>나의 첫째 형제</li>
        <li>나의 둘째 형제</li>
    </ul>

    <script>
        const $me = document.getElementById('me');

        // 자식 요소 탐색
        const $family = document.getElementById('family');
        // 눈에 보이지 않는 텍스트 노드(줄바꿈), 주석 까지 모두 포함하여 혼란을 준다.
        // console.log($family.childNodes);

        // children: 모든 '자식 요소'들을 HTMLCollection으로 반환(텍스트 노드 제외!)
        const $children = $family.children;
        console.log($children);

        // firstElementChild: 첫 번째 '자식 요소' 반환
        const $first = $family.firstElementChild;
        console.log($first)
        $first.style.color = 'red';

        // lastElementChild: 마지막 '자식 요소' 반환
        const $last = $family.lastElementChild;
        console.log($last);

        // 부모 요소 탐색하기
        // parentNode: 나의 '부모 요소'를 반환
        const $parent = $me.parentNode;
        console.log($parent);
        $parent.style.border = '1px solid blue';

        // 형제 요소 탐색하기

        // nextElementSibling: 나의 바로 다음 '형제 요소'를 반환
        const $next = $me.nextElementSibling;
        console.log($next);

        // previousElementSibling: 나의 바로 이전 '형제 요소'를 반환
        const $prev = $next.previousElementSibling;
        console.log($prev); // 이전 형제 요소가 없기 때문에 '나' 자신을 가리키게 된다.
    
    </script>
</body>
```

### 1-3. 요소 정보 확인 및 텍스트 조작

</br>

* `.nodeType`: 노드의 종류를 숫자로 알려줌(1: 요소, 3: 텍스트, 9: 문서)

</br>

* `.nodeValue`: 구식 방법. 쓰지마세용.
    * 오직 '텍스트 노드'의 값만 읽고 쓸 수 있음.
    * '요소 노드' 자체에는 텍스트 정보가 없다고 판단하여 `null`을 반환하기 때문에, 사용하기가 매우 번거로움.

</br>

* `.textContent`: 텍스트 조작 시 사용
    * 요소 노드에 바로 사용 가능.
    * 요소 안의 모든 자손 노드들의 텍스트까지 전부 가져옴. (HTML 태그는 제거)
    * 값을 할당하면, 내부의 모든 자식 노드를 지우고 새로운 텍스트로 깔끔하게 교체함.

</br>

```html
<body>
<h1>요소 정보 확인 및 텍스트 조작</h1>
<pre>
    우리가 선택한 DOM 요소가 어떤 종류인지 확인하고,
    가장 중요한 작업인 '요소 안의 텍스트'를 읽고 쓰는 방법을 배워봅니다.
    </pre>

<hr>

<h3>1. 요소의 종류 확인하기 (참고용)</h3>
<pre>
    모든 DOM 노드는 자신의 종류(요소 노드, 텍스트 노드 등)와 이름을 가지고 있습니다.
    이것을 직접 쓸 일은 거의 없지만, 자바스크립트가 HTML을 어떻게 바라보는지 이해하는 데 도움이 됩니다.
    </pre>

<div id="info-area">div 안의 텍스트</div>

<script>
    const $infoArea = document.querySelector('#info-area');
    const $textInside = $infoArea.firstChild;

    // .nodeType: 노드의 종류를 숫자로 알려줌(1: 요소, 3: 텍스트, 9: 문서)
    console.log($infoArea.nodeType);
    console.log($textInside.nodeType);

    console.log($infoArea.nodeName);
    console.log($textInside.nodeName);
</script>

<hr>

<h3>2. 요소의 텍스트 조작하기 (핵심!)</h3>
<pre>
    요소 안의 텍스트를 바꾸는 데는 여러 방법이 있지만,
    우리는 가장 편리하고 안전한 <b>textContent</b> 프로퍼티에 집중할 것입니다.
    </pre>

<h4>(1) 구식 방법의 한계: `.nodeValue`</h4>
<pre>
    `.nodeValue`는 오직 '텍스트 노드'의 값만 읽고 쓸 수 있습니다.
    '요소 노드' 자체에는 텍스트 정보가 없다고 판단하여 `null`을 반환하기 때문에,
    사용하기가 매우 번거롭습니다.
    </pre>
<div id="value-area">nodeValue</div>
<script>
   const $valueArea = document.getElementById('value-area');
   const $valueText = $valueArea.firstChild;

   // 요소 노드 자체의 nodeValue는 null이다.
   console.log($valueArea.nodeValue);
   // 텍스트를 바꾸려면, 자식인 '텍스트 노드'를 직접 찾아가야만 한다.
   $valueText.nodeValue = 'nodeValue로 변경 완료!'
</script>

<h4>(2) 현대적인 만능 도구: `.textContent`</h4>
<pre>
    `.textContent`는 훨씬 더 똑똑합니다.
    1. 요소 노드에 바로 사용 가능합니다.
    2. 요소 안의 모든 자손 노드들의 텍스트까지 전부 가져옵니다. (HTML 태그는 제거)
    3. 값을 할당하면, 내부의 모든 자식 노드를 지우고 새로운 텍스트로 깔끔하게 교체합니다.
    </pre>

<div id="content-area">여기는 <b>굵은</b> 글씨가 있는 영역입니다.</div>

<script>
    const $contentArea = document.getElementById('content-area');

    // 내부 HTML 태그는 무시하고 텍스트만 전부 가져온다
    console.log($contentArea.textContent);

    // 값을 할당하면, 내부의 모든 것을 지우고 이 텍스트로 교체(HTML 태그 인식 못함)
    $contentArea.textContent = 'textContent로 쉽게 변경! <span>태그는 무시됨</span>'
</script>

<hr>

<h3>3. 결론: 텍스트 조작은 `textContent`를 사용하세요!</h3>
<pre>
    - `.nodeValue`는 텍스트 노드를 직접 찾아가야 하는 번거로움이 있습니다.
    - `.textContent`는 요소 노드에 직접 사용하여 내부의 모든 텍스트를 쉽고 안전하게 다룰 수 있습니다.
    - (참고) `.innerText`라는 비슷한 것도 있지만, CSS 스타일의 영향을 받는 등 복잡한 규칙이 있어
      성능과 일관성을 위해 `textContent`를 사용하는 것이 현대적인 표준입니다.
    </pre>
</body>
```

### 1-4. DOM 조작과 추가

* `innerHTML`: 내부를 완전히 새로운 내용으로 교체
    * 요소 내부의 모든 것을 지우고, 새로운 HTML 문자열로 완전히 교체하는 가장 간단하고 직관적인 방법
    * 단점 : 사용자의 입력을 그대로 넣으면 XSS 공격에 취약함

</br>

* `insertAdjacentHTML`: 기존 내용은 그대로 유지하면서, 원하는 위치 4곳 중 하나를 지정해 새로운 HTML 요소를 '끼워 넣는' 효율적인 방법
    * beforebegin : 시작 전
    * afterbegin : 내부의 가장 앞
    * beforeend : 내부의 가장 뒤
    * afterend : 끝난 후

</br>

* `createElement`: 요소 노드 만들기
* `appendChild` : 마지막 자식으로 추가 / 조립하기 / 노드 이동
* `createDocumentFragment` : 임시 조립공간 만들기

</br>

* `insertBefore` : 기존값 앞에 노드 삽입
* `replaceChild` : 노드 교체
* `removeChild` : 노드 삭제

</br>

```html
<body>
<h1>DOM 요소 조작 및 추가하기 (레고 집 리모델링)</h1>

<hr>

<h3>시나리오 1: 내부 전체를 갈아엎기 (innerHTML)</h3>
<pre>
    `innerHTML`은 요소 내부의 모든 것을 지우고, 새로운 HTML 문자열로 완전히 교체하는 가장 간단하고 직관적인 방법입니다.
    </pre>

<div id="area1">
    <p>기존에 있던 내용입니다.</p>
</div>

<script>
   const $area1 = document.querySelector('#area1');


   // innerHTML로 내부를 완전히 새로운 내용으로 교체
   $area1.innerHTML = '<ul><li>새로운 리스트 아이템</li></ul>';
   // 단점 : 사용자의 입력을 그대로 넣으면 XSS 공격에 취약하다.
   // $area1.innerHTML = `<img src='x' onerror='alert("해킹 공격!")'>`;
</script>

<hr>

<h3>시나리오 2: 특정 위치에 살짝 끼워 넣기 (insertAdjacentHTML)</h3>
<pre>
    `insertAdjacentHTML`은 기존 내용은 그대로 유지하면서,
    원하는 위치 4곳 중 하나를 지정해 새로운 HTML 요소를 '끼워 넣는' 효율적인 방법입니다.
    </pre>
<!-- beforebegin -->
<div id="area2" style="border: 2px solid blue; padding: 10px;">
    <!-- afterbegin -->
    <p>기존 컨텐츠 </p>
    <!-- beforeend -->
</div>
<!-- afterend -->

<script>
   const $area2 = document.getElementById('area2');

    // 4가지 위치에 HTML 삽입하기
    $area2.insertAdjacentHTML('beforebegin', '<p>div 시작 전(beforebegin)</p>');
    $area2.insertAdjacentHTML('afterbegin', '<p>div 내부의 가장 앞(afterbegin)</p>');
    $area2.insertAdjacentHTML('beforeend', '<p>div 내부의 가장 뒤(beforeend)</p>');
    $area2.insertAdjacentHTML('afterend', '<p>div 끝난 후(afterend)</p>');
</script>

<hr>

<h3>시나리오 3: 정밀하게 요소 만들고 조립하기 (createElement / appendChild)</h3>
<pre>
    가장 안전하고 정석적인 방법입니다. 자바스크립트로 직접 요소(레고 블록)를 만들고,
    만들어진 요소를 원하는 위치에 '조립(append)'하는 방식입니다.
    </pre>

<ul id="drink-list">
    <li>커피</li>
</ul>

<script>
   const $drinkList = document.getElementById('drink-list');

   // 'li' 요소 노드를 만든다.
   const $newLi = document.createElement('li')

   // textContent로 안전하게 텍스트를 넣는다.
   $newLi.textContent = '콜라';

   // appendChild로 ul 리스트의 마지막 자식으로 추가한다.
   $drinkList.appendChild($newLi);

   // 여러 요소 효율적으로 추가(DocumentFragment)
   const $fragment = document.createDocumentFragment(); // 임시 조립 공간
   ['사이다', '우유', '환타'].forEach(text => {
        const $li = document.createElement('li');
        $li.textContent = text;
        $fragment.appendChild($li);     // 임시 공간에 먼저 조립
   });
   // 마지막에 한 번만 실제 DOM에 조립
   $drinkList.appendChild($fragment);


</script>

<hr>

<h3>기타 정밀 조작: 삽입, 이동, 교체, 삭제</h3>
<pre>
    `createElement`로 만든 요소들을 더 정밀하게 제어하는 방법들입니다.
    </pre>
<ul id="food-list">
    <li id="pasta">파스타</li>
    <li id="pizza">피자</li>
</ul>

<script>
   const $foodList = document.getElementById('food-list');
   const $drinkList2 = document.getElementById('drink-list');
   const $pasta = document.getElementById('pasta');
   const $pizza = document.getElementById('pizza');

   // 노드 삽입
   const $newFood = document.createElement('li');
   $newFood.textContent = '스테이크';
   // 피자 앞에 스테이크 삽입
   $foodList.insertBefore($newFood, $pizza);

   // 노드 이동 (appendCHild)
   // 이미 존재하는 '피자'를 drink-list로 옮기기
   $drinkList2.appendChild($pizza);

    // 노드 교체 (replaceChild)
    const $newDrink = document.createElement('li');
    $newDrink.textContent = '오렌지주스';
    // drink-list의 첫 요소를 오렌지주스로 교체
    $drinkList2.replaceChild($newDrink, $drinkList2.firstElementChild);

    // 노드 삭제 (removeChild)
    $foodList.removeChild($pasta);
</script>
</body>
```

### 1-5. 어트리뷰트와 프로퍼티
</br>

* **HTML 어트리뷰트**: HTML 문서에 적힌 '초기 설정값'. (ex. '최초 설계도')
    * '프로퍼티(최신값): ', $nickname.value

* **DOM 프로퍼티**:  자바스크립트 객체가 가진 '실시간 최신값'. (ex. '실시간 현황판')
    * '어트리뷰트(초기값): ', $nickname.getAttribute('value')

</br>

* 읽기: `getAttribute('어트리뷰트이름')`
* 쓰기: `setAttribute('어트리뷰트이름', '값')`
* 확인: `hasAttribute('어트리뷰트이름')`
* 지우기: `removeAttribute('어트리뷰트이름')`

</br></br>

*  HTML 표준 속성 외에, 우리만의 데이터를 요소에 '숨겨두고' 싶을 때
    * **data-이름** (케밥 케이스) 형태로 HTML에 어트리뷰트를 작성하고,
    * 자바스크립트에서는 **.dataset.이름** (카멜케이스) 프로퍼티로 쉽게 접근 가능!





</br>

```html
<body>
<h1>어트리뷰트(Attribute)와 프로퍼티(Property)</h1>

<hr>

<h3>1. 어트리뷰트 기본 조작</h3>
<pre>
    HTML 태그에 부여된 속성(attribute)들을 자바스크립트로 읽고, 쓰고, 확인하고, 지우는 방법입니다.
    <b>getAttribute / setAttribute</b> 메서드를 사용하는 것이 가장 명확합니다.
    </pre>

<label for="username">유저명</label>
<input type="text" id="username" value="user01">

<script>
    const $input =document.getElementById('username');

    // 읽기: getAttribute('어트리뷰트이름')
    const inputValue = $input.getAttribute('value');
    console.log(inputValue);

    // 쓰기: setAttribute('어트리뷰트이름', '값')
    $input.setAttribute('value', 'new-user');

    // 확인: hasAttribute('어트리뷰트이름')
    console.log(`class 어트리뷰트 존재 여부: ${$input.hasAttribute('class')}`);

    // 지우기: removeAttribute('어트리뷰트이름')
    $input.removeAttribute('value');
</script>

<hr>

<h3>2. 어트리뷰트 vs 프로퍼티 (초기 설계도 vs 실시간 현황판)</h3>
<pre>
    이 둘의 차이를 이해하는 것은 매우 중요합니다!
    - <b>HTML 어트리뷰트:</b> HTML 문서에 적힌 '초기 설정값'. 마치 건물의 '최초 설계도'와 같습니다.
    - <b>DOM 프로퍼티:</b> 자바스크립트 객체가 가진 '실시간 최신값'. 마치 건물의 '실시간 현황판'과 같습니다.
    </pre>

<label for="nickname">닉네임</label>
<input type="text" id="nickname" value="JSBeginner">

<script>
    const $nickname = document.getElementById('nickname');
    
    // 사용자가 input에 글자를 입력할 때마다 비교
    $nickname.oninput = () => {
        // .value 프로퍼티는 사용자의 입력을 실시간으로 반영
        console.log('프로퍼티(최신값): ', $nickname.value);
        // .getAttribute('value')는 HTML에 적힌 초기값을 그대로 유지
        console.log('어트리뷰트(초기값): ', $nickname.getAttribute('value'))
   }

/*
- 어트리뷰트는 초기 상태를 기억하고, 프로퍼티는 현재 상태를 기억한다.
- 사용자의 입력 값을 가져올 때는 반드시 '프로퍼티(.value)를 사용해야 한다.'
*/

// (참고)
   const $checkbox = document.createElement('input');
   $checkbox.type = 'checkbox';
   $checkbox.setAttribute('checked', '');

   console.log(`어트리뷰트: ${$checkbox.getAttribute('checked')}`);     // '' (빈 문자열)
   console.log(`프로퍼티: ${$checkbox.checked}`);   // true (boolean)
</script>

<hr>

<h3>3. 실무 활용: data 어트리뷰트와 dataset 프로퍼티</h3>
<pre>
    HTML 표준 속성 외에, 우리만의 데이터를 요소에 '숨겨두고' 싶을 때 사용합니다.
    <b>data-이름</b> 형태로 HTML에 어트리뷰트를 작성하고,
    자바스크립트에서는 <b>.dataset.이름</b> 프로퍼티로 쉽게 접근할 수 있습니다.
    </pre>

<ul class="board-list">
    <li data-board-id="13" data-category-name="맛집">망원 맛집 추천 부탁드려요!</li>
    <li data-board-id="15" data-category-name="운동">한강 러닝 크루 구해요!</li>
    <li data-board-id="18" data-category-name="경제">요즘 재태크 어떻게 하시나요?</li>
</ul>

<script>
    const $boardList = document.querySelector('.board-list');

    $boardList.onclick = () => {
    // 클릭된 요소가 li가 아니면 무시
        if(event.target.tagName !== 'LI') return;

        const boardId = event.target.dataset.boardId;   // data-board-id -> boardId (카멜케이스)
        const categoryName = event.target.dataset.categoryName;

        console.log(`선택한 게시글의 ID는 ${boardId}이고, 카테고리는 ${categoryName}입니다.`);
    }
   
</script>

</body>
```

### 1-6. CSS 조작하기
</br>

* `element.style` 프로퍼티 :  해당 요소에 '인라인 스타일' 직접 추가/변경 가능
    * 간단한 동적 효과를 줄 때는 유용
    * 인라인 선택자 우선순위가 매우 높아 스타일 관리 복잡해질 수 있어 비추천

</br>

* `element.classList`: 스타일은 CSS 파일에 미리 정의해두고, 자바스크립트에서는 클래스를 추가/제거/교체하는 것이 가장 현대적이고 효율적인 방법

</br>

* `.className` : 클래스 전체를 덮어쓰기 때문에 위험해서 잘 사용하지 않는다

</br>

* `.add()`: 클래스 추가
* `.toggle()`: 클래스가 있으면 제거, 없으면 추가한다.
* `.contains()`: 특정 클래스가 있는지 확인(true/false)


</br>

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>CSS 조작하기</title>
    <style>
        .box {
            width : 150px;
            height : 150px;
            border : 2px solid black;
            transition: all 0.3s;
        }

        .circle { border-radius: 50%; }
        .red-bg { background-color: crimson; }
        .big-text { font-size: 24px; color: white; }

    </style>
</head>
<body>
<h1>CSS 조작: 인라인 스타일 vs 클래스 제어</h1>

<hr>

<h3>1. 임시 명찰 붙이기 (인라인 스타일: element.style)</h3>
<pre>
    `element.style` 프로퍼티를 사용하면, 해당 요소에 '인라인 스타일'을 직접 추가하거나 변경할 수 있습니다.
    간단한 동적 효과를 줄 때 유용하지만, 스타일 관리가 복잡해진다는 단점이 있습니다.
    </pre>

<div id="box1">첫 번째 박스</div>

<script>
    const $box1 = document.getElementById('box1');

    // .style 프로퍼티로 인라인 스타일 직접 설정
    $box1.style.width = '200px';
    $box1.style.height = '100px';

    $box1.style.backgroundColor = 'skyblue';
    $box1.style.fontSize = '30px';

</script>

<hr>

<h3>2. '직업' 부여하기 (클래스 제어: element.classList)</h3>
<pre>
    스타일은 CSS 파일에 미리 정의해두고, 자바스크립트에서는 클래스를 추가/제거/교체하는 것이
    가장 현대적이고 효율적인 방법입니다. `element.classList`를 사용합니다.
    </pre>

<div id="box2" class="box">두 번째 박스</div>
<button id="changeBtn">모양 바꾸기</button>
<button id="toggleBtn">배경색 토글</button>

<script>
    const $box2 = document.getElementById('box2');
    const $changeBtn = document.getElementById('changeBtn');
    const $toggleBtn = document.getElementById('toggleBtn');

    // .className은 클래스 전체를 덮어쓰기 때문에 위험해서 잘 사용하지 않는다.
    // $box2.className = 'circle';  // .box 클래스가 사라져 버림

    console.log($box2.classList);

    $changeBtn.onclick = () => {
        // .add(): 클래스 추가
        $box2.classList.add('circle', 'red-bg', 'big-text');
        console.log($box2.classList);
    };

    $toggleBtn.onclick = () => {
        // .toggle(): 클래스가 있으면 제거, 없으면 추가한다.
        const isAdded = $box2.classList.toggle('red-bg');
        console.log(isAdded);
    };

    // .contains(): 특정 클래스가 있는지 확인(true/false)
    console.log(`box2가 box 클래스를 가지고 있나요?`, $box2.classList.contains('box'));
</script>
</body>
</html>
```
