## 1. React 개요

### 1-1. React 개요

: React는 **가상 돔(Virtual DOM)** 과 상태 값이 있는 **컴포넌트 (Component)** 개념을 활용하여 효율적인 웹 및 모바일 애플리케이션 개발을 위해 2011년 Facebook에서 소프트웨어 엔지니어인 Jordan Walke에 의해 개발된 **JavaScript 라이브러리**이다.

</br>

### 1-2.  React의 특징

1. `Virtual DOM` 을 사용하여 **빠르고 효율적인 UI 렌더링**을 제공한다.  (성능 향상)
2. `Component` 를 사용하여 UI를 구성하며 `상태(state)` 및 `속성(props)` 을 활용하여 컴포넌트를 렌더링 할 수 있다.(코드의 재사용성 및 개발 생산성 향상)
3. 유연하고 확장 가능한 라이브러리로써 현재는 React Native를 통해 모바일 애플리케이션 개발에도 사용되고 있다.

</br>

### 1-3. React의 주요 요소

#### 1-3-1. 엘리먼트(Element)
💡 요소 노드, 어트리뷰트 노드, 텍스트 노드로 만들어지는 가상 DOM 개념

</br>

#### 1-3-2. 컴포넌트(Component)
💡 엘리먼트를 반환하는 개념을 가진 화면의 구성 단위
* 컴포넌트에는 클래스형 컴포넌트와 함수형 컴포넌트가 있다.
* react 16 이후부터는 함수 기반의 컴포넌트 생성 방법이 주를 이루고 있다

</br>

#### 1-3-3. Virtual DOM
💡 모든 변경 사항에 대해 전체 DOM을 업데이트 하는 대신 변경 사항이 발생한 부분만 업데이트하여 DOM 조작을 최소화 하기 위한 개념
* Render Tree를 참고하여 Virtual DOM이 생성되며 이러한 가상 돔(Virtual DOM) 개념을 통해 애플리케이션의 성능을 크게 향상 시키고 대규모 애플리케이션 개발에 매우 유용하다.


</br>

#### 1-3-4. JSX
💡 JSX는 React에서 UI를 구성하는 데 사용하는 자바스크립트의 확장 문법
* HTML과 유사한 문법을 사용하여 UI를 작성할 수 있게 하며 직관적이고 쉽게 코드를 작성할 수 있으며 Babel과 같은 도구를 통해 JavaScript코드로 변환된다.



</br></br>

### 1-4. React의 동작 원리
💡 웹 브라우저의 렌더링 엔진 동작 과정
:`HTML Parsing` → `CSS Parsing` → `Render` → `Layout` → `Paint`

</br>

1. **HTML Parsing**: HTML을 파싱해서 DOM Tree를 생성한다.
2. **CSS Parsing**: CSS 파일을 파싱해서 CSSOM Tree를 생성한다.
3. **Render**: 두개의 Tree를 결합하여 Render Tree 생성
4. **Layout**: Render Tree를 화면에 배치하는 것과 관련하여 각 노드의 위치와 크기를 계산하여 화면 상에 실제 픽셀로 변환
하고 레이어를 생산
5. **Paint**: 레이어를 생성하여 실제 화면에 표시


</br></br>

## 2. 컴포넌트(Component)
### 2-1. JSX
#### 2-1-1. 컴포넌트와 JSX


* 컴포넌트란?
    - UI를 재사용 가능한 '부품'으로 나눈 것이다(예: 버튼, 헤더, 프로필 카드 등)
    - React 엘리먼트를 반환하는 '자바스크립트 함수'이다.
    - 반드시 '대문자'로 시작해야 한다.

</br>

```html

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
</head>
<body>
    <div id="root"></div>

    <script type="text/babel">
        /* 1. 클래스형 컴포넌트: 앞 글자를 반드시 대문자로 시작 */
        class TitleClass extends React.Component {
            render() {
                return React.createElement(
                    'h1',
                    { className: "classComponent"},
                    '클래스형 컴포넌트입니다.'
                )
            }
        }

        /* 2. 함수형 컴포넌트 */
        function OldWayComponent() {
            return React.createElement(
                'div',
                null,
                React.createElement('h1', { className: 'greeting'}, 'createElement 방식'),
                React.createElement('p', null, '코드가 길고 복잡하다.')
            
            );
        }

        /* JSX 방식 */
        function NewWayComponent() {
            return (
                <div>
                    <h1 className="greeting">JSX 방식</h1>
                    <p>코드가 간단하다</p>
                </div>
            );
        }

        /* 컴포넌트란?
        - UI를 재사용 가능한 '부품'으로 나눈 것이다(예: 버튼, 헤더, 프로필 카드 등)
        - React 엘리먼트를 반환하는 '자바스크립트 함수'이다.
        - 반드시 '대문자'로 시작해야 한다.
        */

        function App() {
            return (
                // 여러 요소를 하나로 묶어주기  위한 빈 태그(Fragment)
                <>
                    <OldWayComponent />
                    <hr />
                    <NewWayComponent />
                </>
            )
        }

        ReactDOM.createRoot(document.getElementById('root')).render(<App />);

    </script>
    
</body>
</html>
```

#### 2-1-2. JSX

* JSX란?
    - JavsScript의 확장 문법
    - JavaScript에서 HTML의 markup(태그) 방식처럼 엘리먼트를 생성하여 Component를 만들 수 있다.
    - 단, JSX는 공식적인 JavaScript 문법이 아니므로 바벨(babel)이라는 트랜스파일링 툴을 필요로 한다. 



</br>

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
</head>
<body>
    <div id="root"></div>

    <script type="text/babel">
        // JSX 안에서 사용할 자바스크립트 데이터와 함수
        const user = {
            name: '홍길동',
            age: 20
        };

        function introduce(user) {
            return `안녕하세요, 저는 ${user.name}이고 ${user.age}세 입니다.`;
        }

        function handleClick() {
            alert('버튼이 클릭되었습니다!')
        }

        const customStyle = {
            backgroundColor: 'cornflowerblue',
            color: 'white',
            padding: '10px',
            borderRadius: '5px'
        };

        // 컴포넌트
        function JsxComponent() {
            return (
                <>
                    <h2>1. { } 안에 자바스크립트 표현식을 넣을 수 있다.</h2>
                    <h3>이름: {user.name}</h3>
                    <p>소개: {introduce(user)}</p>

                    <h2>2. HTML 속성과 약간 다른 규칙을 따른다.</h2>
                    {/* class는 className으로, onclick은 onClick으로 (camelCase) */}
                    <button className="my-button" onClick={handleClick}>
                        클릭해보세요
                    </button>

                    <h2>3. 인라인 스타일은 '객체' 형태로 전달해야 한다.</h2>
                    <p style={customStyle}>
                        이 문단에는 커스텀 스타일을 적용하였다.
                    </p>

                    <h2>4. 모든 태그는 반드시 닫혀야 한다.</h2>
                    한줄짜리 태그도 예외는 없다. <br /> <hr /> <input />
                </>
            )
        }

        ReactDOM.createRoot(document.getElementById('root')).render(<JsxComponent />);
    </script>
</body>
</html>
```

#### 2-1-3. 렌더링과 VDOM

💡 **Root DOM Node**
: ReactDOM에서 관리하며 React의 엘리먼트들이 렌더링 될 하나의 DOM
* React Element를 루트 DOM에 렌더링 하기 위해 **ReactDOM.createRoot(루트 DOM 노드).render(렌더링 할 엘리먼트)** 로 전달하면 된다'

</br>

* React에서 엘리먼트를 바꿀 때는 **엘리먼트 단위로 변경**해야 한다.(불변객체, immutable) 엘리먼트는 **특정 시점의 UI**를 의미한다.

</br>

* 기존의 가상 돔과 새로운 변화로 생성된 가상 돔(Render Tree를 기반으로 생성 된)을 통해 **변화가 있는 부분만 변경이 일어난다.**


</br>




</br>

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
</head>
<body>
    <div id="root"></div>

    <script type="text/babel">
        function Clock() {
            return (
                <div>
                    <h1>실시간 시계</h1>
                    <h2>현재 시간: {new Date().toLocaleTimeString()}</h2>
                </div>
            )
        }

        const root = ReactDOM.createRoot(document.getElementById('root'));

        function tick() {
            root.render(<Clock />);
        }

        setInterval(tick, 1000);

    </script>
    
</body>
</html>
```

### 2-2. Props
#### 2-2-1. Props

* **Props**: 부모 컴포넌트가 자식 컴포넌트에게 데이터를 전달하는 '통로'
    * 읽기 전용(read-only) 데이터이다. (자식은 Props를 수정할 수 없음)
    * 데이터는 항상 위에서 아래로 흐른다. 
    * 부모가 props를 전달하지 않았을 경우를 대비한 '기본값'을 설정할 수 있다.


</br>

* **children-props**
    * **props.children**을 통해 **컴포넌트 태그 사이에 있는 값을 컴포넌트 내부에서 활용**할 수 있다.


</br>

* **propTypes**
    * 각 props이 어떤 '타입'이어야 하는지, '필수'인지 아닌지를 검사한다.
    * 규칙이 맞지 않으면 브라우저 콘솔에 경고를 표시하여 실수를 방지한다.

</br>

💡 props로 넘어올 때의 속성명과 컴포넌트 태그 사이 값을 **객체 구조분해 할당(Distructuring)** 을 통해 **props의 속성에 접근하지 않고 간편하게 활용**할 수 있다.


</br>

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
    <script src="https://unpkg.com/prop-types@15.8.1/prop-types.js"></script>
</head>
<body>
    <div id="root"></div>

    <script type="text/babel">

        /**
         * Props: 부모 컴포넌트가 자식 컴포넌트에게 데이터를 전달하는 '통로'
         * - 읽기 전용(read-only) 데이터이다. (자식은 Props를 수정할 수 없음)
         * - 데이터는 항상 위에서 아래로 흐른다. 
         */

        // 부모가 props를 전달하지 않았을 경우를 대비한 '기본값'을 설정할 수 있다.
        function Greeting({name = '기본이름', favoriteNumber, children}) {
            return (
                <>
                    <h1>안녕하세요, {name}!</h1>
                    <h2>제가 좋아하는 숫자는 {favoriteNumber} 입니다.</h2>
                    <p>
                        <strong>전달된 자식 요소(children): {children}</strong>
                    </p>
                </>
            )
        }

        /**
         * propTypes
         * - 각 props이 어떤 '타입'이어야 하는지, '필수'인지 아닌지를 검사한다.
         * - 규칙이 맞지 않으면 브라우저 콘솔에 경고를 표시하여 실수를 방지한다.</div>
         */
        Greeting.propTypes = {
            name: PropTypes.string,
            favoriteNumber: PropTypes.number
        }

        function App() {
            const name1 = '홍길동';
            const name2 = '유관순';

            return (
                <Greeting name={name1} favoriteNumber={3}>
                    React 공부 중이에요~!
                </Greeting>
            )
        }

        ReactDOM.createRoot(document.getElementById('root')).render(<App />);
    
    </script>
    
</body>
</html>
```

### 2-3. State
#### 2-3-1. useState 

* **state**:  컴포넌트 내부에서 바꿀 수 있는(바뀔 수 있는) 값
    * props는 컴포넌트가 사용되는 과정에서 부모 컴포넌트가 설정하고 주는 읽기 전용 값이었지만 state는 컴포넌트 내부에서 설정되는 값이다.

</br>

* 클래스형 컴포넌트에서는 state 직접 사용 가능
* **함수형 컴포넌트에서는 직접 state 사용 불가능**
    * 함수형 컴포넌트에서는 **useState**라는 hooks로 제공하고 있다
    * `hooks` -> use로 시작하는 함수들






</br>

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
</head>
<body>
    <div id="root"></div>

    <script type="text/babel">

        console.log(React); // hooks -> use로 시작하는 함수들

        const {useState} = React;

        function MessageManager() {
            // [상태 값, 상태 변경 함수] = useState(초기값);
            // 배열 구조분해할당
            const [message, setMessage] = useState('초기 상태 메세지입니다.');
            const [textColor, setTextColor] = useState('black');

            console.log('MessageManager 컴포넌트가 렌더링 되었습니다.');

            const handleEnter = () => {
                setMessage('안녕하세요! 환영합니다.');
                setTextColor('blue');
            }

            const handleLeave = () => {
                setMessage('안녕히 가세요! 다음에 또 만나요.');
                setTextColor('red');
            }

            return (
                <div>
                    <h1>useState</h1>
                    <h2 style={{ color: textColor }}>{message}</h2>

                    <button onClick={handleEnter}>입장</button>
                    <button onClick={handleLeave}>퇴장</button>
                </div>
            )
        }

        function Counter() {
            const [number, setNumber] = useState(0);

            const increaseByTwo = () => {
                setNumber((preveNumber) => preveNumber + 1);
                setNumber((preveNumber) => preveNumber + 1);
            }

            return (
                <div>
                    <h1>카운터</h1>
                    <h2>현재 숫자: {number}</h2>
                    <button onClick = {() => setNumber(number + 1)}>1</button>
                    <button onClick={() => {
                        setNumber(number + 1);
                        setNumber(number + 1);
                    }}>+2(동작 안함)</button>
                    <button onClick={() => setNumber(number - 1)}>-1</button>
                    <button onClick={increaseByTwo}>+2</button>
                </div>
            )
        }

        function App() {
            return (
                <>
                    <MessageManager />
                    <hr />
                    <Counter />
                </>
            );
        }

        ReactDOM.createRoot(document.getElementById('root')).render(<App />);
    
    </script>
    
</body>
</html>
```

### 2-4. Event
#### 2-4-1. Event 핸들링

💡 이벤트 속성에서 **중괄호를 활용**해 **이름 없는 익명 함수로 이벤트가 발생하면 실행 될 이벤트 핸들러 함수를 작성할 수 있다.**

</br>

이벤트 핸들러에서는 **이벤트 객체를 활용**하거나 **state를 변화** 시킬 수 있고 **그 외에 추가적으로 진행 되어야 할 내용을 작성**해 클릭 이벤트 발생 시 활용할 수 있다

</br></br>

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">

    <script type="text/babel">

        const {useState} = React;

        function SignupFormBasic() {

            const [username, setUsername] = useState('');
            const [email, setEmail] = useState('');

            const handleSignup = () => {
                alert(`아이디: ${username} 이메일: ${email} 회원가입 완료!`);
                setUsername('');
                setEmail('');
            }

            return (
                <div>
                    <h2>기본적인 이벤트 처리</h2>
                    <input
                        type="text"
                        placeholder='아이디'
                        value={username}
                        onChange={e => setUsername(e.target.value)}
                        />
                    <input
                        type="email"
                        placeholder='이메일'
                        value={email}
                        onChange={e => setEmail(e.target.value)}
                        />
                    <button onClick={handleSignup}>가입하기</button>
                </div>
            );
        }

        function SignupFormAdvanced() {
            // 관련된 상태들을 하나의 객체로 묶어서 관리!
            const [form, setForm] = useState({
                username: '',
                email: ''
            });

            const handleChange = (e) => {
                // e.target에서 name과 value를 미리 추출
                const { name, value } = e.target;

                setForm({
                    ...form,            // 기존 객체 복사
                    [name]: value   // 변경이 일어난 input의 name을 key로 삼아 새로운 value로 덮어씀
                });
            };

            const handleSignup = () => {
                alert(`아이디: ${username} 이메일: ${email} 회원가입 완료!`);
                setForm({ username: '', email: ''});
            }

            const { username, email } = form;

            return (
                <div>
                    <h2>효율적인 이벤트 처리</h2>
                    <input
                        type="text"
                        name="username" // state 객체의 key와 동일한 이름
                        placeholder='아이디'
                        value={username}
                        onChange={handleChange}
                        />
                    <input
                        type="email"
                        name="email"
                        placeholder='이메일'
                        value={email}
                        onChange={handleChange}
                        />
                    <button onClick={handleSignup}>가입하기</button>
                </div>
            );
        }

        function CustomButton({ event, children }) {
            return (
                <button
                    onClick={event}
                    style={{ backgroundColor: 'black', color: 'white', border: 'none', padding: '10px'}}>
                    {children}
                </button>
            )
        }

        function App() {
            const showWelcomeMessage = () => {
                alert('우리 사이트에 오신 것을 환영합니다.');
            }

            return(
                <>
                    <SignupFormBasic />
                    <hr />
                    <SignupFormAdvanced />
                    <div>
                        <h2>Props로 이벤트 함수 전달하기</h2>
                        <CustomButton event={showWelcomeMessage}>
                            환영 메시지 보기
                        </CustomButton>
                    </div>
                </>
            )
        }


        ReactDOM.createRoot(document.getElementById('root')).render(<App />);
    
    </script>
    
</body>
</html>
```
