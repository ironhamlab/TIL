### 4-2. API
#### 4-2-1. fetch

</br>

💡 자바스크립트를 사용해 **새로고침 없이(비동기식) 서버에서 새로운 정보**를 받아올
수 있다.
* promise 객체 기반이 아닌 Ajax를 이용해서 비동기식으로 처리할 수도 있지만
Ajax 외에도 fetch api를 이용할 수 있다.
* fetch는 구식 브라우저에서는 지원하지 않지만 대부분의 모던 브라우저가 지원하
고 있다.
* promise 기반의 비동기 처리를 위해 axios.js를 쓸 수도 있다.

</br></br>

* **fetch 기본 사용 방법**
```js
let promise = fetch(url, [options]);
```
* **url**: 접근하고자 하는 url
* **options**: 선택 매개변수로 http method나 headers, body 내용을 객체로 지정할 수 있다.
    * options에 아무 값도 넣지 않으면 기본 GET 메소드(8가지 http method 중)로 요청을 하게 된다.


</br>

```js
<body>
    <div id="root"></div>

    <script type="text/babel">

        // fetch 기본문법
        // let promise = fetch(url, [option]);

        async function callAPI() {
            const promise = fetch('https://jsonplaceholder.typicode.com/users')
            console.log(promise);
            console.log(promise['[[PromiseResult]]']);
            
            const response = await fetch('https://jsonplaceholder.typicode.com/users')
            console.log(response);

            console.log(`본문 사용 여부: ${response.bodyUsed}`);

            // response.json()
            // 본문 내용을 json으로 파싱해서 자바스크립트 객체로 변환
            // 비동기이므로 await 필수!!
            const responseJson = await response.json();
            console.log(responseJson);

            // response는 한 번만 꺼내 쓸 수 있다.
            console.log(`본문 사용 여부: ${response.bodyUsed}`);

        }
        callAPI();
    </script>
    
</body>
```

#### 4-2-2. then & async/await

</br>

#### * then
💡 async/await를 활용하지 않고 fetch의 반환 값인 **promise가 제공하는 then 메소드를 활용**하여 **메소드 체이닝 방식으로 순차적인 비동기 요청 및 결과 값 확인**을 할 수 있다.

</br>

#### * async/await
* 내부적으로는 then과 동일한 로직이나 조금 더 표현이 깔끔하게 다듬어진 버전


</br>

```js
<body>
    <script>

        // 1. fetch(url) 호출
        // 2. response.json() 호출

        const API_URL = 'https://jsonplaceholder.typicode.com/users';

        // 1. .then() 체이닝 방식
        function fetchDataWithThen() {
            fetch(API_URL)
                // 1. 서버의 응답(Response)객체가 도착하면 실행    
                .then(response => {
                    console.log(response);
                    if (!response.ok) {
                        throw new Error(`HTTP error ${response.status}`)
                    }
                    return response.json();
                })
                // 2. .json() Promise가 성공적으로 완료되면, 파싱된 데이터를 받아서 실행
                .then(data => {
                    console.log(data);
                })
                .catch(error => {
                    console.error('데이터를 가져오는데 실패했습니다:', error)
                })
        }
        // fetchDataWithThen();

        // 방법2. async/await 사용
        async function fetchDataWithAsyncAwait() {
            try {
                const response = await fetch(API_URL);
                console.log(response);

                if (!response.ok) {
                    throw new Error(`HTTP error: ${response.status}`);
                }
                const data = await response.json();
                console.log(data);

            } catch(error) {
                console.log(error);
            }
        }

        fetchDataWithAsyncAwait();
    </script>

</body>
```

#### 4-2-3. axios

</br>


💡 axios는 데이터 **변환처리(json()) 등을 하지 않아도 되므로 편리하게 사용**할 수 있다. (이미 파싱된 데이터가 **data라는 조회 결과** response 객체의 프로퍼티로 들어있다.)

</br>

* 자세한 사용 방법은 아래의 링크를 참고하여 확인할 수 있다.
(https://github.com/axios/axios#example)

</br></br>

* **axios를 사용하기 위해서는 head에 해당 태그 넣어줘야 함**
```html
    <script crossorigin src="https://unpkg.com/axios/dist/axios.min.js"></script>

```

</br></br>

```js
<body>
    <script>
        const API_URL = 'https://jsonplaceholder.typicode.com/users/1';

        // fetch 사용
        async function callApiWithFetch() {
            try{
                const response = await fetch(API_URL);
                //  fetch는 if(!response.ok) 꼭 있어야 함(http 에러를 reject로 잡지 못하기 때문에)
                const data = await response.json(); // .json()으로 직접 파싱
                console.log(data);
            } catch(error) {
                console.error(error);
            }
        }
        // axios 사용
        async function callApiWithAxios() {
            try{
                const response = await axios.get(API_URL); // .get(), .post()등 직관적 메소드 사용
                const data = response.data; // json 파싱이 자동으로 되어 response.data에 담겨있다
                console.log('axios data: ', data);
                console.log ('axios response', response);
            } catch(error) {
                console.error(error);
            }
        }
        callApiWithFetch();
        callApiWithAxios();
    </script>
</body>
```

#### 4-2-4. github imoji practice

</br>

💡 github api에서 제공하는 이모지 데이터를 통해 비동기 통신할 수 있다.


</br>

```js
<body>
    <div id="root"></div>

    <script type="text/babel">

        const { useState, useEffect } = React;

        // 요청 URL : https://api.github.com/emojis

        // 사용자의 입력을 받고, '검색' 이벤트가 발생했음을 부모에게 알린다.
        function SearchBox ({onSearch}) {

            const [inputText, setInputText] = useState('');

            const handleSearchClick = () => {
                // 전달 받은 onSearch 함수 사용
                onSearch(inputText);
            };

            return (
                <>
                    <input 
                        type="text"
                        placeholder='이모지 이름을 입력하세요'
                        value={inputText}
                        onChange={e => setInputText(e.target.value)}
                    />
                    <button onClick={handleSearchClick}>검색</button>
                </>
            );
        }

        // 부모가 주는 상태에 따라 화면을 다르게 보여준다.
        function ImageBox({imgUrl, loading}) {

            if(loading) {
                return <p>로딩 중...</p>
            }
            if (imgUrl) {
                return <img src={imgUrl} alt="emoji" width="100" height="100" />;
            }
            return <p>이모지를 검색해주세요</p>;
        }

        // 모든 데이터와 상태 관리(로딩, 전체 이모지 목록, 검색 결과 URL)를 관리
        // API 통신을 책임지고, 자식들의 행동에 따라 상태를 업데이트 한다.
        function App() {

            const [loading, setLoading] = useState(true);   // 로딩상태
            const [emojis, setEmojis] = useState(null);     // 전체 이모지 목록
            const [imgUrl, setImgUrl] = useState(null);     // 검색 결과 이미지 URL

            useEffect(() =>{
                // 마운트시 딱 한 번 api 호출해서 전체 이모지 목록을 가져온다.
                    async function fetchEmojis() {
                        try {
                            const response = await axios.get('https://api.github.com/emojis');
                            setEmojis(response.data);   // 가져온 데이터를 state에 저장
                        } catch(error) {
                            console.error(error);
                        } finally {
                            setLoading(false);  // 로딩 완료
                        }
                    }
                    fetchEmojis();
            }, []);

            // 검색된 이모지 이름을 이용하여 일치하는 이미지를 찾아, imgUrl 설정 
            const handleSearch = (emojiName) => {
                if(!emojis || emojiName.trim() === '') {
                    setImgUrl(null);
                    return;
                }
                // emojis 객체에서 emojiName을 키로 가진 값을 찾음
                const foundUrl = emojis[emojiName];
                setImgUrl(foundUrl || null); // 찾았으면 url을, 못 찾았으면 null 설정
            };

            return (
                <>
                    <h1>이모지 검색기</h1>
                    <SearchBox onSearch={handleSearch}/>
                    <br/>
                    <ImageBox imgUrl={imgUrl} loading={loading}/>
                </>
            );
        }

        ReactDOM.createRoot(document.getElementById('root')).render(<App />);
    </script>
</body>
```

### 4-3. Data Component

#### 4-3-1. itemList

</br>

💡 useEffect를 활용할 때는 **useEffect의 콜백함수에서 state에 변화를 주는 경우에는 주의**해서 작성해야 한다.
* 변화가 발생한 해당 state를 **의존성 배열에서 관리하면 state의 변화로 인해 리렌더링이 무한히 발생**하게 된다.
* 이는 개발자 도구를 활용하지 않는 이상 쉽게 발견하기 어려워 **리소스 낭비**가 발생할 수 있다.
* 따라서 의존성 배열을 빈 배열로 주어 **마운트 시점에만 동작**하게 해야 한다.



</br>

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
    <script crossorigin src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
    <style>
        .item {
            background-color: bisque;
            border: 1px dotted black;
            width: 350px;
            display: inline-block;
            margin: 10px;
        }
    </style>
</head>
<body>
    <div id="root"></div>

    <script type="text/babel">

        const { useEffect, useState } = React;

        function Title() {
            return <h1>회원 목록</h1>;
        }

        function ItemList() {
            const [users, setUsers] = useState([]);  // 서버에서 받아올 유저 목록
            const [loading, setLoading] = useState(true); // 로딩상태
            const [error, setError] = useState(null);   // 에러상태
           
            useEffect(() => {
                fetch('https://jsonplaceholder.typicode.com/users')
                    .then(response => {
                        if (!response.ok) {
                            throw new Error('네트워크 응답 문제가 있습니다.');
                        }
                        return response.json();
                    })
                    .then(responseUsers => setUsers(responseUsers))
                    .catch(error => {
                        console.error('데이터를 불러오는 데 실패했습니다.', error);
                        setError(error);    // 에러 발생 시 에러 상태에 저장  
                    })
                    .finally(() => setLoading(false));
            }, []);

            // Early Return 패턴
            if (loading) {
                return <p>로딩 중...</p>;
            }
            if (error) {
                return <p>오류가 발생했습니다: {error.message}</p>;
            }

            return (
                <div>
                    {users.map(user => <Item key={user.id} user={user} />)}    
                </div>
            );
        }

        function Item({user}) {
            return (
                <div className="item">
                    <h4>{user.name}</h4>
                    userId : {user.id} <br/>
                    email : {user.eamil} <br/>
                    phone : {user.phone} <br />
                    {/* 옵셔널 체이닝 연산자 사용(에러 방지) */}
                    company name: {user.company?.name}
                </div>
            );
        }

        function App () {
            return (
                <>
                    <Title />
                    <ItemList />
                </>
            )
        }

        ReactDOM.createRoot(document.getElementById('root')).render(<App />);
    </script>
    
</body>
</html>
```
