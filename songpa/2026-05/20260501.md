## 6-2. 배열
### 6-2-2. 2차원 배열
- 2차원 이상의 배열은 다차원 배열이라고 한다. 일부 인덱스는 또 다른 배열의 주소를 보관하는 배열 역할을 한다.
- 즉, 2차원 배열은 1차원 배열 여러 개를 하나로 묶어서 관리하는 배열이다.
- 더 많은 차원의 배열을 사용할 수 있지만 일반적으로는 2차원 배열보다 더 높은 차원의 배열은 사용 빈도가 극히 적다.(인지 범위 초과)
- 2차원 배열은 **[ ]** 를 2개를 사용하여 표현한다.

</br></br>

**<다차원 배열 예제>**

```java
/*
다차원 배열

즉, 2차원 배열은 1차원 배열 여러 개를 하나로 묶어 관리하는 배열이다.
  */

// 2차원 배열 선언 및 할당
// 정변 배열

int[][] iarr2 = {{1, 2, 3, 4, 5,},{6, 7, 8},{11, 12, 13}};

// 중첩 반복문을 이용한 값 대입

for (int i = 0; i < iarr.length; i++) {
    for(int j = 0; j < iarr[i].length; j++) {
        iarr[i][j]=value++;
    }

for(int i = 0; i < iarr.length; i++) {
    for(int j = 0; j < iarr[i].length; j++) {
```

## 6-3. 배열의 복사
### 6-3-1. 배열의 복사란?
자바에서는 배열은 목적에 따라 복사를 해야 할 경우가 있으며 유형으로는 얕은 복사와 깊은 복사가 있다.

</br>

### 6-3-2. 복사의 종류
배열의 복사 종류로는 2가지가 있다.
1. 얕은 복사(shallow copy) : stack 의 주소값만 복사, 원본을 공유 할 목적
2. 깊은 복사(deep copy) : heap의 배열에 저장된 값을 복사, 원본과 사본을 분리하여 관리 할 목적

</br></br>

### 6-3-3. 얕은 복사 개요

* 얕은 복사는 stack에 저장되어 있는 배열의 주소값만 복사한다는 것이다.
* 따라서 두 개의 레퍼런스 변수는 동일한 배열의 주소값을 가지고 있다.
* 하나의 레퍼런스 변수에 저장된 주소 값을 가지고 배열의 내용을 수정(값 변경) 을 하게 되면
다른 레퍼런스 변수로 배열에 접근했을 때도 동일한 배열을 가리키고 있기 때문에 변경된 값이 반영되어 있다.

</br>

**<배열의 얕은 복사 예제>**

```java
/*
[얕은 복사]
stack의 주소값만 복사하므로, 두 변수가 동일한 배열(heap)을 참조한다.
따라서 한쪽 배열을 수정하면 다른 쪽에도 영향이 간다.
  */

// 원본 배열
int[] originArr = {1, 2, 3, 4, 5};

int[] copyArr = originArr;

// hashCode()를 통해 두 변수가 같은 주소를 가리키는지 확인
System.out.println(originArr.hashCode());
System.out.println(copyArr.hashCode());
/* 동일한 주소로 나옴
1791741888
1791741888
  */

//원본값 확인    // 5
System.out.println(originArr[4]);

// 얕은 복사한 배열의 인덱스값 변경
copyArr[4] = 90;

// 원본값 재확인  // 90
System.out.println(originArr[4]);
```

</br></br>

### 6-3-4. 깊은 복사 개요
* 깊은 복사는 heap에 생성된 배열이 가지고 있는 값을 또 다른 배열에 복사를 해 놓은 것이다.
* 서로 같은 값을 가지고 있지만, 두 배열은 서로 다른 배열이기에, 하나의 배열에 변경을 하더라도 다른 배열에는 영향을 주지 않는다.
* 깊은 복사는 얕은 복사와 달리 새롭게 할당한 힙 영역에 기존 배열의 값을 복사한 후 새롭게 생성된 배열의 주솟값을 넘겨주는 것이다.

</br></br>

**<배열의 깊은 복사 방법>**

```java
import java.util.Arrays;

public class Application2 {
    public static void main(String[] args) {

        /*
        [깊은 복사]
        heap에 새로운 배열을 생성하고, 기존 배열의 값을 그대로 복사한다.
        따라서 두 배열은 서로 독립적이므로, 한쪽을 수정해도 다른 쪽에 영향이 없다.
         */

        int[] originArr = {1, 2, 3, 4, 5};
        System.out.println("originArr : " + originArr.hashCode());
        System.out.println("-----------------------------");
        // originArr : 1791741888

        // 1. for문을 이용한 수동 복사
        int[] copyFor = new int[originArr.length];
        for(int i = 0; i < originArr.length; i++) {
            copyFor[i] = originArr[i];
        }
        print("copyFor", copyFor);
        // copyFor hashCode: 883049899, array: [1, 2, 3, 4, 5]


        // 2. Arrays.copyOf() 이용
        // Arrays.copyOf(원본배열, 복사할 길이);
        int[] copyOf = Arrays.copyOf(originArr, originArr.length);
        print("copyOf", copyOf);
        // copyOf hashCode: 1721931908, array: [1, 2, 3, 4, 5]


        // 3. System.arraycopy()
        int[] arrayCopy = new int[originArr.length];
        //System.arraycopy(원본, 원본시작위치, 사본, 사본시작위치, 복사할 길이);
        System.arraycopy(originArr, 0, arrayCopy, 0, originArr.length);
        print("arrayCopy", arrayCopy);
        // arrayCopy hashCode: 1198108795, array: [1, 2, 3, 4, 5]


        // 4. clone()
        int[] copyClone = originArr.clone();
        print("copyClone", copyClone);
        // copyClone hashCode: 214126413, array: [1, 2, 3, 4, 5]


        // 깊은 복사의 경우 주소값이 서로 다르므로, 한쪽의 인덱스 값을 바꿔도 다른쪽이 영향받지 않음
        copyClone[0] = 99;

        print("originArr", originArr);
        print("copyClone", copyClone);
        /*
        originArr hashCode: 1791741888, array: [1, 2, 3, 4, 5]
        copyClone hashCode: 214126413, array: [99, 2, 3, 4, 5]
         */

        /* clone()은 깊은 복사인가요?
        기본형 배열에서는 깊은 복사처럼 동작하지만,
        참조형(객체, 2차원배열 등)에서는 얕은 복사이다.
         */
    }


    public static void print(String name, int[] arr) {
        System.out.println(name + " hashCode: " + arr.hashCode() + ", array: " + Arrays.toString(arr));
    }
}
```

```java
/*
[선택 정렬]
가장 작은 값을 찾아 맨 앞으로 보내는 과정을 반복하는 것
  */

int[] arr = {2, 5, 4, 6, 1, 3};
System.out.println("정렬 전: " + Arrays.toString(arr));

for(int i = 0; i < arr.length -1; i++) {
    int minIndex = i;   // 일단 현재 자리(i)에 있는 값이 가장 작다고 가정
    for (int j = i; j < arr.length; j++) {
```

**<버블 정렬 방법>**

```java
/*
[버블 정렬]
인접한 두 원소를 비교하여, 큰 값을 오른쪽으로 계속해서 이동시킨다.
한 회차가 끝나면 가장 큰 값이 배열의 맨 뒤에 위치하게 된다.
  */

int[] arr = {2, 5, 4, 6, 1, 3};
System.out.println("정렬 전: " + Arrays.toString(arr));

// i : 정렬이 확정된 영역의 시작 인덱스 (뒤에서부터)
for(int i = arr.length -1; i >= 0; i--) {
    // j : 비교할 대상의 인덱스 (앞에서부터)
    for(int j = 0; j < i; j++) {
        if (arr[j] > arr[j + 1]) {
            int temp = arr[j];
            arr[j] = arr[j + 1];
            arr[j + 1] = temp;
        }
    }
    System.out.println((arr.length - i) + "회차 정렬 후 : " + Arrays.toString(arr));
    /*
    1회차 정렬 후 : [2, 4, 5, 1, 3, 6]
    2회차 정렬 후 : [2, 4, 1, 3, 5, 6]
    3회차 정렬 후 : [2, 1, 3, 4, 5, 6]
    4회차 정렬 후 : [1, 2, 3, 4, 5, 6]
    5회차 정렬 후 : [1, 2, 3, 4, 5, 6]
    6회차 정렬 후 : [1, 2, 3, 4, 5, 6]
      */
}
System.out.println("정렬 후 : " + Arrays.toString(arr));
/*
정렬 전: [2, 5, 4, 6, 1, 3]
정렬 후 : [1, 2, 3, 4, 5, 6]
  */
```

```java
/* 배열과 정렬을 응용하여 중복 없는 로또 번호 생성하기 */

// 내 코드
// 1. 6개의 숫자를 담을 배열 생성
int[] mylotto = new int[6];

// 2. 중복되지 않는 난수를 생성하여 배열에 담기
mylotto[0] = (int)(Math.random() * 45) + 1;
for(int i = 0; i < mylotto.length; i++) {
    for(int j = 0; j < i; j++) {
        while(mylotto[i] == 0 || mylotto[i] == mylotto[j]) {
            mylotto[i] = (int)(Math.random() * 45) + 1;
        }
    }
}
// 3. 정렬하여 출력
Arrays.sort(mylotto);
System.out.println(Arrays.toString(mylotto));


// 수업 코드
// 1. 6개의 숫자를 담을 배열 생성
int[] lotto = new int[6];

// 2. 중복되지 않는 난수를 생성하여 배열에 담기
for (int i = 0; i < lotto.length; i++) {
    lotto[i] = (int) (Math.random() * 45) + 1;

    // 중복 검사
    for (int j = 0; j < i; j++) {
        if(lotto[i] == lotto[j]) {
            i--;    // 이번 회차 무효 (다시 뽑기)
            break;
        }
    }
}

// 3. 정렬하여 출력
Arrays.sort(lotto);
System.out.println("로또 번호 : " + Arrays.toString(lotto));
```

# 1. 클래스와 객체
## 1-1. 클래스란?
* 서로 다른 타입의 데이터와 메소드를 정의하여 사용자 정의의 타입을 만들 수 있는데, 이것을 클래스라고 한다.
* 즉, 클래스는 사용자 정의의 자료형이다.


</br>

**<클래스 예제>**

Member.java
```java
public class Member {
    /*
    [클래스]
    객체를 만들기 위한 설계도
    객체가 어떤 데이터(속성)와 어떤 기능(메소드)을 가져야 하는지 정의

    [필드 == 속성 == 인스턴스(객체) 변수]
     */

    String id;
    String pwd;
    String name;
    int age;
    char gender;
    String[] hobby;
```

## 1-2. 캡슐화

* 캡슐화는 유지보수성 증가(낮은 결합도)를 위해 필드의 직접 접근을 제한하고, public 메소드를 이용하여 간접적으로 접근하여 사용할 수 있도록 클래스를 작성하는 기법이다.
* 클래스를 작성할 시 특별한 목적이 아닌 이상 캡슐화가 기본적인 원칙으로 사용되고 있다.

</br></br>

### 1-2-1. 필드에 직접 접근 시 발생할 수 있는 문제점

A. 필드에 올바르지 않는 값이 들어가도 통제가 불가능하다.
B. 필드의 이름이나 자료형을 변경할 때 사용하는 쪽에도 수정 영향을 미친다.

</br></br>

### 1-2-2. 캡슐화를 적용하여 문제점 해결

A. 필드에 직접 접근하지 못하도록 private 접근 제어자 사용

|private|	O|	|	| |


B. public 메소드를 이용하여 간접적으로 접근하도록 사용

C. 메소드 내에 값을 검증하는 로직 추가

```java
/*
[접근제한자]
클래스 혹은 클래스의 멤버(필드)에 참조 연산자로 접근할 수 있는 범위를 제한하기 위한 키워드

(+) public : 모든 패키지에서 접근 허용
(#) protected : 동일 패키지에서 접근 허용 (단, 상속 관계에 있는 경우 다른 패키지에서도 접근 허용)
(~) default : 동일 패키지 내에서만 접근 허용 (작성하지 않는 것이 default)
(-) private : 해당 클래스 내부에서만 접근 허용

클래스, 생성자, 클래스의 멤버(필드, 메소드)에 모두 사용 가능하다.
단, 클래스 선언 시 사용하는 접근제한자는 public과 default만 사용 가능하다.
  */

/*
[캡슐화]
유지보수성을 증가시키기 위해 필드의 직접 접근을 제한하고
public 메소드를 이용해 접근하여 사용할 수 있도록 만든 기술이다.
  */

private String nickname;

private int age;

/*
[Getter와 Setter 메소드]
Getter(접근자): 내부 필드의 값을 읽어서 전달하는 역할을 하는 메소드(읽기 전용)
Setter(변경자): 외부에서 전달된 값을 받아, 내부 필드의 값을 설정 또는 변경하는 역할을 하는 메소드
  */

public void setAge(int age) {
    if(age >= 0) {
        this.age = age;
    } else {
        System.out.println("나이는 음수일 수 없어!!!!!");
        this.age = 0;
    }
}

public int getAge() {
    return this.age;
}
```
