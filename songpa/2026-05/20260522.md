서버 인증 상태
Cookie - 서버가 쿠키를 주면 브라우저가 쿠키 저장, 다음 요청 때 request에 자동으로 붙여서 서버에 전송함.
- 값이 브라우저에 저장
- 다음 요청에 자동 전송
- 사용자가 확인하거나 조작 가능
- 아이디 기억하기, 간단한 설정값 등에 사용


Session
- 실제 값이 서버에 저장
- 브라우저는 JSESSIONID 쿠키만 저장
- 로그인 상태 관리에 자주 사용됨
- 서버 메모리나 세션 저장소에 대한 관리 필요함
