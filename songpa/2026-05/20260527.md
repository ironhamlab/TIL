* 스프링 프레임워크는 서블릿이 하던 일을 더 쉽게 내부적으로 구현해두었음

#### <Spring Core 관련>

* 의존객체를 직접 만들지 않고 외부에서 넣어주는 방식을 **의존성 주입(Dependency Injection)** 이라고 함.

</br>

* **Spring Container** : Spring이 객체를 만들고 보관하고 관리하는 공간

* **Bean** : Spring Container가 관리하는 객체

</br></br>

* **Bean 등록 방법 2가지**
1. XML 기반 (요즘은 잘 안씀)
2. Java Config 기반
    * java config의 @Bean
    * ComponentScan의 @Component


</br>

**<주요 흐름>**
Controller -> Service -> Repository
Servlet -> Service -> DAO -> JDBC(-DB)

### <오늘 내용>

* 스프링의 삼각형
IoC, DI, AOP (, PSA)

</br>

* `@Component` = Spring이 관리할 일반 Bean

* `@Controller` = 웹 요청 처리 계층 Bean

* `@Service` = 비즈니스 로직 계층 Bean

* `@Repository` = 데이터 접근 계층 Bean

* `@Autowired` = 필요한 의존 객체를 자동으로 주입

</br>

* **주입 방식 3가지**
1. 필드 주입
2. setter 주입
3. 생성자 주입

</br>

* `@Primary` = 기본 우선 Bean 지정
* `@Qualifier` = 이름으로 특정 Bean 지정, Primary보다 우선순위 높음
* `@Collection` = List<T> 주입 - 같은 타입 Bean 여러 개를 한 번에 주입

</br></br>

* **Bean Scope**
    - **singleton(기본)** = Spring 컨테이너 안에서 Bean 객체를 하나만 만들고 공유 (Service, Repository)
    - **prototype** = getBean()으로 요청할 때마다 새로운 Bean 객체를 만듦
    (`@Bean` `@Scope("prototype")`     : 이 Bean은 getBean()으로 요청할 때마다 새 객체를 만들어 반환한다.)

</br></br>

* **Bean Life Cycle**
- Bean은 생성, 의존성 주입, 초기화 ,사용, 소멸 흐름을 가진다.
- initMethod, destroyMethod로 특정 시점에 메소드를 실행할 수 있다.
    * initMethod : 초기화 메서드 (bean이 생성되고 필요한 준비가 끝난 뒤 실행되는 메서드)
    * destroyMethod : 소멸 메서드 (Container가 종료되면서 Bean이 정리되기 직전에 실행되는 메서드)
    * 예시 코드
    `@Bean(initMethod = "openShop", destroyMethod = "closeShop")`
</br>
- `@PostConstruct`, `@PreDestroy` 방식도 있다(참고)
=> 이 경우 build.gradle에 dependency 추가 필요 (`implementation 'jakarta.annotation:jakarta.annotation-api:3.0.0'`)

</br></br>

* **외부 설정값**
- 변경 가능성이 있는 값은 Java 코드에 직접 박아두지 않는 것이 좋다.
- properties 파일에 값을 작성하고 `@PropertySource`, `@Value` 로 읽을 수 있다.

</br></br>

* **AOP** : 공통 관심사를 핵심 로직에서 분리하고, 필요한 실행 지점에 자동을 끼워 넣는 방식
</br>
* 핵심 관심사 : 실제 업무기능
* 공통 관심사 : 로그, 트랜잭션 처리 등 여러곳에서 반복되는 기능

</br></br>

package com.ohgiraffers.section01;

import org.springframework.context.ApplicationContext;
import org.springframework.context.annotation.AnnotationConfigApplicationContext;

public class Application {
    public static void main(String[] args) {

        ApplicationContext context
                = new AnnotationConfigApplicationContext("com.ohgiraffers.section01");

        MemberService memberService = context.getBean("memberService", MemberService.class);

        System.out.println("========== selectMembers ==============");
        System.out.println(memberService.selectMembers());

        System.out.println("=========== selectMember ==============");
        System.out.println(memberService.selectMember(1L));
    }
}

**LoggingAspect.java**

```java
package com.ohgiraffers.section01;

import org.aspectj.lang.JoinPoint;
import org.aspectj.lang.annotation.Aspect;
import org.aspectj.lang.annotation.Before;
import org.aspectj.lang.annotation.Pointcut;
import org.springframework.stereotype.Component;

@Aspect // AOP용 클래스 표시
@Component
public class LoggingAspect {

    // Pointcut :  어떤 메서드에 공통 기능을 적용할지 고르는 조건
    // com.ohgiraffers.section01 패키지 안의 이름이 Service로 끝나는 클래스의 모든 메서드 실행지점
    @Pointcut("execution(* com.ohgiraffers.section01.*Service.*(..))")
    public void logPointcut() {
    }

    @Before("LoggingAspect.logPointcut()")
    // JoinPoint : 현재 실행 지점의 정보를 담고 있는 객체
    public void logBefore(JoinPoint joinPoint) {
        System.out.println("Before joinPoint.getTarget() : " + joinPoint.getTarget());
        System.out.println("Before joinPoint.getSignature(): " + joinPoint.getSignature() );
    }
}
```

**MemberDAO.java**

```java
package com.ohgiraffers.section01;

import org.springframework.stereotype.Repository;

import java.util.Date;
import java.util.HashMap;
import java.util.Map;

@Repository // DB 커넥션을 가지는 쪽에 많이 작성
public class MemberDAO {

    private final Map<Long, MemberDTO> memberMap;

    public MemberDAO() {
        memberMap = new HashMap<>();
        memberMap.put(1L, new MemberDTO(1L, "유관순"));
        memberMap.put(2L, new MemberDTO(2L, "홍길동"));
    }

    public Map<Long, MemberDTO> selectMembers() {
        return memberMap;
    }

    public MemberDTO selectMember(Long id) {
        MemberDTO returnMember = memberMap.get(id);

        if (returnMember == null) {
            throw new RuntimeException("해당하는 id의 회원이 없습니다.");
        }

        return returnMember;
    }
}
```

package com.ohgiraffers.section01;

public class MemberDTO {

    private Long id;
    private String name;

    public MemberDTO() {
    }

    public MemberDTO(Long id, String name) {
        this.id = id;
        this.name = name;
    }

    public Long getId() {
        return id;
    }

    public void setId(Long id) {
        this.id = id;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    @Override
    public String toString() {
        return "MemberDTO{" +
                "id=" + id +
                ", name='" + name + '\'' +
                '}';
    }
}

**MemberService.java**

```java
package com.ohgiraffers.section01;

import org.springframework.stereotype.Service;

import java.util.Map;

@Service   // DAO를 호출해서 사용할 서비스 로직을 작성할 클래스
public class MemberService {

    private final MemberDAO memberDAO;

    // 생성자 하나니까 @Autowired 생략 가능
    public MemberService(MemberDAO memberDAO) {
        this.memberDAO = memberDAO;
    }

    public Map<Long, MemberDTO> selectMembers() {
        System.out.println("selectMembers 메소드 실행");
        return memberDAO.selectMembers();
    }

    public MemberDTO selectMember(Long id) {
        System.out.println("selectMember 메소드 실행");
        return memberDAO.selectMember(id);
    }
}
```

#### [느낀 내용]

* 다양한 annotation들이 있고 Bean 을 관리하기 위한 방법도 다양하다는 것을 알게 되었다. Spring Boot 파트에서 다른 방법들도 배우게 될 것 같아 기대된다.
* 스프링, 특히 스프링 코어 부분은 굉장히 어려울 것이라고 생각했는데 코드를 따라가다보니 조금씩 이해가 된다. 그래도 아직 이해가 100% 된 것은 아니라서 여러번 반복하고 실습해봐야 할 것 같다.
