* 단원명 : Spring
* 학습 주제 : Spring Boot

---


#### [학습 내용]

**Filter**
- Spring MVC에 들어오기 전 요청
- Dispatcher Servlet 앞단에서 동작
- 인코딩, CORS, 인증/인가 등
- 웹 요청 전체에 걸쳐야 하는 작업에 자주 사용

</br>

**Interceptor**
- Spring MVC 기능
- Controller 실행 전후 요청 처리
- DS이 controller를 찾은 뒤, Controller 호출 전후에 동작

</br>

**AOP**
- 메서드 실행 전후 공통 로직 처리
- Service, Repository 등 다양한 Bean 메서드에 적용 가능
- HTTP 요청이 아니어도 Spring Bean 에 있는 메서드 실행 전후에 동작

</br>

* preHandle: Controller 실행 전에 호출, false를 반환하면 요청 중단
* afterCompletion: 요청 처리가 끝난 뒤 호출됨, 로그, 처리시간 측정, 정리작업에 적합

</br>

**200 OK**
- 조회 성공
- 응답 body 있음

</br>

**201 Created**
- 새 리소스 생성 성공
- Location header로 새 리소스 위치 안내 가능

</br>

**204 No Content**
- 요청 처리 성공
- 응답 body 없음
- 수정/삭제 성공에 자주 사용

</br>

**ResponseMessage**
- 응답 body 구조를 일정하게 맞추기 위한 DTO

package com.ohgiraffers.interceptor;

import org.springframework.context.annotation.Configuration;
import org.springframework.web.servlet.config.annotation.InterceptorRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

@Configuration
public class WebConfiguration implements WebMvcConfigurer {

    private final StopwatchInterceptor stopwatchInterceptor;
    private final ApiKeyInterceptor apiKeyInterceptor;

    // 생성자 주입
    public WebConfiguration(StopwatchInterceptor stopwatchInterceptor, ApiKeyInterceptor apiKeyInterceptor) {
        this.stopwatchInterceptor = stopwatchInterceptor;
        this.apiKeyInterceptor = apiKeyInterceptor;
    }
    // 인터셉터 적용 설정 (경로, 순서 등)
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(stopwatchInterceptor)
                .addPathPatterns("/api/v1/**")  // 적용 경로
                .excludePathPatterns("/error")  // 제외 경로
                .order(1);                      // 인터셉터 실행순서, 숫자가 작을수록 먼저 실행

        registry.addInterceptor(apiKeyInterceptor)
                .addPathPatterns("/api/v1/admin/**")
                .excludePathPatterns("/error")
                .order(2);
    }
}

package com.ohgiraffers.restapi.section02.valid;

import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

// 프로젝트 전체의 REST API 예외를 JSON응답으로 관리하는 클래스
@RestControllerAdvice
public class ExceptionController {

    // UserNotFoundException이 발생하면, 이 메소드가 가로채서 처리
    @ExceptionHandler(UserNotFoundException.class)
    public ResponseEntity<ErrorResponse> UserException(UserNotFoundException e){
        String code = "ERROR_CODE_0000";
        String description = "회원 정보 조회 실패";
        String detail = e.getMessage(); // 예외에 담긴 메세지 사용

        return new ResponseEntity<>(new ErrorResponse(code, description, detail), HttpStatus.NOT_FOUND);
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ErrorResponse> methodValidException(MethodArgumentNotValidException e) {
        String code = "";
        String description = "";
        String detail = e.getBindingResult().getFieldError().getDefaultMessage();
        String bindResultCode = e.getBindingResult().getFieldError().getCode();

        switch (bindResultCode) {
            case "NotNull":
                code = "ERROR_CODE_0001";
                description = "필수 값이 누락되었습니다."; break;
            case "NotBlank":
                code ="ERROR_CODE_0002";
                description ="필수 값이 공백입니다."; break;
            case "Size":
                code = "ERROR_CODE_0003";
                description="글자 수를 확인해주세요"; break;
            default:
                code="ERROR_CODE_9999";
                description="요청 값 검증에 실패했습니다.";
        }
        return new ResponseEntity<>(new ErrorResponse(code, description, detail), HttpStatus.BAD_REQUEST);

    }
}
