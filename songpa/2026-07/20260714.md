## 1. 형변환 (Casting)

**컴퓨터 연산 원칙**
1. 동일한 자료형 사이에서만 연산이 가능하다.
2. 연산 결과 역시 동일한 자료형이다.

### 암묵적 형변환
자동으로 형변환 후 연산이 처리되는 경우.

```python
print(3 + 1.23)   # int + float -> float + float = 4.23
print(3 + True)    # int + bool -> int + int = 4 (True는 1로 취급)
print(3 + int("5"))  # 8
```

- bool로의 암묵적 형변환도 존재한다.
  - 값이 존재하면 `True`, 값이 없으면(`0`, `''`, `[]`, `{}`) `False`로 취급.

### 명시적 형변환
`int()`, `float()`, `str()` 등으로 직접 타입을 변환.

```python
x = int(input('점수입력: '))  # 빈 문자열이면 ValueError 발생
print(int(3.5) + 4)
print(float('3.5') + 4)
```

- **컨테이너 자료형 간 변환**: `list()`, `tuple()`, `set()`, `dict()`
```python
list((1, 2, 3))          # tuple -> list
tuple([1, 2, 3])          # list -> tuple
set([1, 2, 2, 3])          # 중복 제거
dict([('a', 100), ('b', 200)])  # list 안의 tuple -> dict
```

## 2. 연산자 우선순위

`()` > `**` > 단항연산자(`+x`,`-x`,`~x`) > `*,/,//,%` > `+,-` > 시프트(`<<,>>`) > `&` > `^` > `|` > 비교연산자 > `not` > `and` > `or` > 조건표현식(`if-else`) > `lambda` > `:=`(왈러스) > `=`(대입, 가장 낮음)

참고: https://docs.python.org/3/reference/expressions.html

## 3. 삼항 연산자 (조건 표현식)

```python
(참일때 값) if (조건식) else (거짓일때 값)
```

```python
print('참' if True else '거짓')   # 참

num = int(input('정수입력: '))
print('홀' if num % 2 == 1 else '짝')
```

두 값 비교해서 큰수/작은수 구분하는 예시:
```python
a, b = int(input()), int(input())
big = a if a > b else b
small = a if a < b else b
```

## 4. 조건문 (if / elif / while)

- `if ~ elif ~ else`: 조건을 위에서부터 순차적으로 검사하고, 처음 참인 블록만 실행.
- `while`: 조건이 참인 동안 반복 실행. 조건이 거짓이 되는 시점(종료조건)을 명확히 설계해야 무한루프를 방지할 수 있다.

```python
score = 85
if score >= 90:
    print('A')
elif score >= 80:
    print('B')
else:
    print('C')

i = 0
while i < 5:
    print(i)
    i += 1
```

## 5. 내포 (Comprehension)

리스트/딕셔너리를 한 줄의 반복문으로 생성하는 문법.

```python
# list comprehension
nums = [n + 100 for n in range(1, 101)]
my_fruits = [f * 3 for f in fruits]

# 조건 포함
nums_even = [n for n in range(1, 101) if n % 2 == 0]

# dict comprehension
target = {k: v for k, v in zip(students, scores)}
```

## 6. 함수 (Function)

- 절차적/반복적 실행 코드를 담은 자료형. 선언 후 호출해서 사용.
- 호출 시 값(매개인자)을 전달하고, 실행 결과(리턴값)를 돌려받을 수 있다.

### 매개변수 vs 매개인자
- **매개변수(parameter)**: 함수 선언부의 변수(공간)
- **매개인자(argument)**: 함수 호출부에서 전달하는 실제 값

### 호출 방식
1. **위치 매개인자**: 선언 순서대로 값이 대입 (`test(10, 20)`)
2. **키워드 매개인자**: 이름으로 대입, 순서 무관 (`test(b=2, a=1)`)

### 기본값 지정
```python
def print_info(name, age, has_married=True):
    ...
```
- 기본값이 있는 매개변수는 뒤쪽에 위치해야 하며, 기본값 없는 매개변수는 호출 시 생략 불가.

### Packing 연산자 (`*args`, `**kwargs`)
- `*args`: n개의 위치 매개인자를 튜플로 받음
- `**kwargs`: n개의 키워드 매개인자를 딕셔너리로 받음
- packing 매개변수는 일반 매개변수의 오른쪽에 위치해야 함

```python
def hello(name, *scores):
    print(f'{name}의 점수: {scores}')

def user_info(name, age, **configs):
    print(configs)

def sample(a, b, c=99, *args, **kwargs):
    print(a, b, c, args, kwargs)
```

### Unpacking 연산자
- packing과 기호는 동일(`*`, `**`)하지만, 사용 위치(값 자리)에 따라 구분됨.
```python
names = ['홍길동', '홍진경', '홍난파']
test(*names)  # 개별 요소로 전달

*lst, = zip(nums, chars)  # 언패킹으로 리스트 생성
```

### 함수는 1급 시민 객체
- 변수에 대입 가능, 리턴값으로 사용 가능(클로저의 기반 개념).
```python
doo = foo          # 변수에 함수 대입
def get_func():
    def bar():
        print('bar 호출')
    return bar      # 함수를 리턴값으로 사용
f = get_func()
f()
```

## 7. Lambda 함수

한 줄로 작성하는 익명 함수 표현식: `lambda 매개변수부: 리턴값`

```python
f = lambda x: x ** 2
add = lambda a, b=3: a + b       # 기본값 지정 가능
adder = lambda *args: sum(args)  # packing도 가능

squares = [(lambda x: x ** 2)(n) for n in range(1, 11)]
```

## 8. 내장(built-in) 모듈 — map / filter / reduce

`dir(__builtins__)`로 import 없이 사용 가능한 함수/속성 목록 확인 가능.

### map
iterable의 각 요소에 함수를 적용한 결과를 map 객체로 반환.
```python
lens = [*map(lambda x: len(x), texts)]

# 여러 iterable을 동시에 사용
list(map(lambda mid, final: (mid + final) / 2, mid_terms, final_terms))
```

### filter
함수 적용 결과가 `True`인 요소만 남긴다.
```python
evens = list(filter(lambda x: x % 2 == 0, nums))
hongs = list(filter(lambda n: n.startswith('홍'), names))
```

### reduce (functools)
iterable을 순회하며 누적 연산 후 단일 값을 반환.
- 매개변수: `함수(누적값, 현재값)`, iterable 객체, 초기값(선택, 생략 시 첫 요소가 초기값)

```python
from functools import reduce

total = reduce(lambda acc, current: acc + current, nums, 0)
max_num = reduce(lambda a, b: a if a > b else b, numbers)
```

## 오늘의 핵심 정리
- **형변환**: 암묵적(자동) vs 명시적(직접 호출) 구분, 컨테이너 간 변환도 가능
- **삼항연산자 / if-elif-else / while**: 조건 분기와 반복의 기본 골격
- **컴프리헨션**: 반복문을 한 줄로 축약, list/dict 모두 가능
- **함수**: 매개변수·인자 구분, packing(`*args`,`**kwargs`)과 unpacking(`*`) 대칭 구조, 1급 시민 객체로서 변수 대입/리턴 가능
- **lambda**: 이름 없는 한 줄 함수, 주로 map/filter/reduce와 함께 사용
- **map/filter/reduce**: 함수형 프로그래밍 스타일로 반복 로직을 간결하게 표현하는 3종 세트
