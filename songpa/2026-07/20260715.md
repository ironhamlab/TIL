## 1. 날짜/시각 (datetime)

```python
from datetime import datetime

today = datetime.today()
now = datetime.now()
```

- `now.year`, `.month`, `.day`, `.hour`, `.minute`, `.second`: 각 요소별 접근
- `now.date()`, `now.time()`: 날짜만 / 시간만 분리
- `now.weekday()`: 요일을 정수(0=월 ~ 6=일)로 반환 → 리스트 인덱싱으로 요일 문자열 매핑 가능

### 형식표현 (strftime / strptime)
| 코드 | 의미 |
|---|---|
| `%Y` | 연도(4자리) |
| `%y` | 연도(2자리) |
| `%m` | 월 |
| `%d` | 일 |
| `%H` | 시(24시간제) |
| `%I` | 시(12시간제) |
| `%M` | 분 |
| `%S` | 초 |
| `%a` | 요일(축약) |

```python
now.strftime('%Y-%m-%d %H:%M:%S')       # datetime -> 문자열
datetime.strptime(text, '%y-%m-%d %I:%M:%S')  # 문자열 -> datetime
```

### timedelta / D-Day 계산
```python
from datetime import timedelta, date

future_date = now + timedelta(days=5, hours=1)
past_date = now - timedelta(days=5)

diff = date(2026, 12, 24) - date.today()
print(f'D-{diff.days}일 남았습니다.')
```

## 2. 객체지향 프로그래밍 (OOP)

- 객체(메모리 조각)를 사용해 프로그램을 전개하는 방식
- 클래스 = 속성(변수, 객체가 아는 것) + 메소드(함수, 객체가 할 수 있는 것)

### 클래스 / 객체 기본
```python
class Person:
    def __init__(self, name, age):
        """생성자: 객체 생성 시 속성 초기화. 모든 메소드의 첫 인자는 self(현재 객체)"""
        self.name = name
        self.age = age

    def hello(self, greeting='안녕'):
        print(f'{greeting}, 나는 {self.age}살 {self.name}이야~~')

hong = Person('홍길동', 33)
hong.hello('여보세요')
```

### 클래스 속성/메소드 vs 인스턴스 속성/메소드
- **클래스 속성**: 클래스에 저장되어 모든 인스턴스가 공유
- **인스턴스 속성**: 각 인스턴스마다 다르게 저장
- **클래스 메소드(`@classmethod`)**: 첫 인자로 `cls`(클래스 자체)를 받음
- **정적 메소드(`@staticmethod`)**: `self`/`cls` 없이 독립적으로 동작

```python
class SongpaStudent:
    COURSE_NAME = 'JAVA&Spring Backend developer AI AGENT Camp'  # 클래스 속성

    def __init__(self, name, nth):
        self.name = name   # 인스턴스 속성
        self.nth = nth

    def introduce(self):   # 인스턴스 메소드
        print(f'안녕하세요, {self.nth}기 {self.name}입니다.')

    @classmethod
    def goodmornig(cls):
        print(f'안녕하세요~ {cls.COURSE_NAME} 여러분.')

    @staticmethod
    def goodbye(name):
        print(f'수고하셨습니다, {name}님.')
```

### 객체지향 4대 설계 원칙
1. **캡슐화**: 속성/메소드를 한 클래스에 묶고, 속성의 외부 직접 접근을 막음
2. **상속**: 부모 클래스의 속성/메소드를 자식 클래스가 선언 없이 사용
3. **다형성**: 상속 기반으로 하나의 객체가 여러 타입처럼 동작
4. **추상화**: 객체가 가져야 할 보편적인 속성/메소드를 추출해 설계

## 3. 캡슐화 (Encapsulation)

- `__속성명`처럼 언더스코어 두 개(private)를 붙이면 클래스 외부에서 직접 접근 불가
- 유효성 검사가 필요한 로직(입금/출금 등)은 반드시 메소드를 통해서만 처리하도록 강제

```python
class Account:
    def __init__(self, name, balance):
        self.__name = name
        self.__balance = balance

    def deposit(self, money):
        if money > 0:
            self.__balance += money
        else:
            print('입금액이 유효하지 않습니다.')

    def withdraw(self, money):
        if 0 < money <= self.__balance:
            self.__balance -= money
        else:
            print('출금액이 유효하지 않습니다.')
```
→ 캡슐화 없이 `acc.balance = ...` 처럼 직접 수정하면 값이 검증 없이 변경되어 데이터 무결성이 깨질 수 있음.

### getter/setter (`@property`)
```python
class User:
    def __init__(self, name, point):
        self.__name = name
        self.__point = point

    @property
    def point(self):
        """getter - 속성처럼 읽기(point())가 아닌 point로 접근)"""
        return self.__point

    @property
    def name(self):
        return self.__name

    @name.setter
    def name(self, name):
        """setter - 값 재할당 시 검증 로직을 넣을 수 있음"""
        self.__name = name
```

## 4. 모듈 (Module)

- `.py` 파일 자체를 의미. 관련 있는 변수/함수/클래스를 묶어 재사용성을 높임
- private 변수(`__`로 시작)는 외부에서 접근 불가

```python
import math
print(dir(math))   # 모듈이 제공하는 속성/함수 목록
print(__name__)     # 현재 모듈 이름 ('__main__' 또는 모듈명)
```

### 사용자 모듈 가져오기 방식 비교
```python
import songpawork.my_math                     # 전체경로로 접근: songpawork.my_math.x
from songpawork import my_math as m            # 별칭 사용 (추천)
from songpawork.my_math import x, pi           # 필요한 것만 개별 import
# from songpawork.my_math import *             # 비추천: 이름 충돌 위험
```

## 6. 입출력 (IO) - `open()`

```python
f = open('파일경로', '모드', encoding='인코딩')
```

| 모드 | 의미 | 파일 없을 때 |
|---|---|---|
| `'r'` | 읽기 | `FileNotFoundError` |
| `'w'` | 쓰기(덮어쓰기) | 새로 생성 |
| `'a'` | 이어쓰기 | 새로 생성 |
| `'x'` | 배타적 생성 | 이미 있으면 오류 |
| `'b'` | 바이너리 | - |
| `'t'` | 텍스트(기본) | - |

- `read()`: 전체를 문자열로, `readline()`: 한 줄씩, `readlines()`: 모든 줄을 리스트로
- 파일은 사용 후 반드시 `close()` → **`with` 블럭 사용 시 자동으로 닫힘 (추천)**

```python
with open('sample.txt', 'w', encoding='utf-8') as f:
    f.write(text)

with open('sample.txt', 'r', encoding='utf-8') as f:
    for line in f:          # 한 줄씩 순회
        print(line, end='')

with open('sample.txt', 'r', encoding='utf-8') as f:
    while line := f.readline():   # 왈러스 연산자로 반복 읽기
        print(line, end='')
```

## 7. 예외 처리 (Exception / Error)

- Python은 Exception과 Error를 엄격히 구분하지 않으며, `TypeError`/`ValueError`/`MemoryError` 등은 모두 `Exception`의 하위 클래스
- 계층 구조: `BaseException` > `Exception` > 각종 세부 예외

### try / except / else / finally
```python
try:
    print(10 / 0)
except ZeroDivisionError as e:
    print('0으로 나누면 안됩니다.')
except IndexError as e:
    print('존재하지 않는 인덱스입니다.')
except Exception as e:
    print('오류 발생:', e)
else:
    print('예외 없이 정상 종료된 경우 실행')
finally:
    print('무조건 실행')
```
- `except:`로 모든 예외를 무시(`pass`)하는 것은 디버깅을 어렵게 하므로 지양

### raise - 의도적으로 예외 발생시키기
```python
def foo():
    raise NotImplementedError('서비스 중비중입니다.')
```

## 8. 유효 범위 (Scope)

- **global scope**: 전역에 선언된 변수, 어디서든 접근 가능
- **local scope**: 블럭(함수 등) 내부에 선언된 변수, 블럭을 벗어나면 접근 불가
- 변수 우선순위: 가장 가까운 스코프의 변수를 먼저 사용 (지역변수가 전역변수를 가림)

```python
x = 33  # 전역
def koo():
    x = 55  # 지역 (전역과 별개)
    print(x)  # 55
koo()
print(x)  # 33 (변경되지 않음)
```

### call by value vs call by reference
- **call by value**: 값 자체가 복사되어 전달(immutable 타입 - 숫자, 문자열 등) → 함수 내부에서 변경해도 원본에 영향 없음
- **call by reference**: 참조 주소가 전달(mutable 타입 - list, dict 등) → 함수 내부에서 변경하면 원본도 변경됨

```python
def f1(v):
    v = 200
    return v
v = 100
v = f1(v)  # 200 (재할당 받아야 반영됨)

def f2(lst):
    lst[1] *= 100
lst = [1, 2, 3]
f2(lst)     # [1, 200, 3] (원본 자체가 변경됨)
```

## 9. Numpy 기초

### list vs numpy 배열
- 파이썬 list의 `+`는 **연결(concat)**, Numpy 배열의 `+`는 **같은 위치 요소별 계산**
```python
import numpy as np
[1,2,3] + [4,5,6]          # [1, 2, 3, 4, 5, 6] (연결)
np.array([1,2,3]) + np.array([4,5,6])  # [5 7 9] (요소별 덧셈)
```

### 배열 생성 함수
| 함수 | 설명 |
|---|---|
| `np.array(list)` | 리스트를 배열로 변환 |
| `np.zeros(shape)` | 0으로 채움 (기본 dtype=float) |
| `np.ones(shape)` | 1로 채움 |
| `np.full(shape, value)` | 지정한 값으로 채움 |
| `np.arange(start, stop, step)` | 간격(step) 기준 생성 |
| `np.linspace(start, stop, num)` | 개수(num) 기준 균등 분할 생성 |

```python
np.arange(5, 20, 3)      # [ 5  8 11 14 17] - 간격 기준
np.linspace(0, 10, 6)     # [ 0. 2. 4. 6. 8. 10.] - 개수 기준
```

### 배열 속성
| 속성 | 설명 |
|---|---|
| `.shape` | 배열의 모양(튜플): (행,) / (행, 열) / (깊이, 행, 열) |
| `.ndim` | 차원 수 |
| `.size` | 전체 요소 개수 (shape의 곱) |
| `.dtype` | 요소의 자료형 (하나의 자료형만 저장 가능, 섞이면 자동 변환됨) |

### 행렬 연산 (axis 개념)
- `axis=0`: **열(column) 방향** 연산 → 과목별 평균처럼 "세로로" 계산
- `axis=1`: **행(row) 방향** 연산 → 학생별 평균처럼 "가로로" 계산

```python
scores = np.array([[80, 90, 70], [95, 85, 88], [70, 78, 74]])
scores.mean()           # 전체 평균
scores.mean(axis=0)     # 과목별(열) 평균
scores.mean(axis=1)     # 학생별(행) 평균
```

## 오늘의 핵심 정리
- **datetime**: `now`/`today`로 현재 시각 획득, `strftime`/`strptime`으로 문자열↔날짜 변환, `timedelta`로 날짜 연산(D-Day 계산 활용)
- **OOP**: 클래스=속성+메소드, 인스턴스 vs 클래스 속성/메소드 구분, `@classmethod`/`@staticmethod` 용도 차이
- **캡슐화**: `__` private 속성 + `@property`/`@속성.setter`로 안전하게 값 검증 후 노출
- **모듈/os/IO**: `import`로 코드 재사용, `os`로 파일시스템 제어, `with open()`으로 안전하게 파일 다루기
- **예외처리**: `try-except-else-finally` 구조, 구체적 예외부터 순서대로 잡기, `raise`로 의도적 예외 발생
- **scope**: 지역변수가 전역변수보다 우선, call by value(불변) vs call by reference(가변) 구분이 함수 부작용 이해의 핵심
- **Numpy**: list와 달리 요소별 연산, `shape/ndim/size/dtype`으로 배열 구조 파악, `axis=0`(열)/`axis=1`(행) 기준 통계 연산 구분이 헷갈리기 쉬운 포인트
