#### [학습 내용]

1. **Numpy 인덱싱 & 슬라이싱**

    * 1D/2D 인덱싱, 슬라이싱(::step, ::-1), fancy indexing(arr[[1,3,5]]), boolean indexing(arr[arr>=80])
    * 헷갈렸던 row/col 구분은 [행, 열] 순서 고정으로 정리

</br></br>

2. **배열 연산 & Broadcasting**

    * 요소별 연산, 스칼라 연산, abs/round/ceil/floor
    * Broadcasting 규칙: 뒤쪽 차원부터 비교 → 같거나 1이면 가능

    ```
    (2,3)+(3,) ✅ / (2,3)+(2,1) ✅ / (2,3)+(2,) ❌
    ```

</br></br>

3. **Shape 변형**

* reshape(요소 개수 고정, -1은 자동계산), flatten(복사본) vs ravel(원본 메모리 공유 가능), transpose/.T

</br></br>

4. **집계 함수**

* sum/mean/max/min, argmax/argmin(값이 아니라 위치 반환), std
* axis=0(열/세로, 과목별), axis=1(행/가로, 학생별) — 자주 헷갈리는 부분

</br></br>

5. **벡터 & 유사도**

* Norm(np.linalg.norm), 내적(np.dot, @)
* Dot product의 한계: 크기(스케일)에 영향받음 → 방향만 비교하려면 Cosine similarity 필요
* Cosine similarity는 크기 불변(scale-invariant), 결과가 1에 가까울수록 방향 유사

</br></br>

6. **GPT 핵심 개념 흉내내기 (가장 중요)**

* Tokenize: 문장을 토큰 단위로 분리
* Embedding: 단어 → 벡터, cosine similarity로 의미 유사도 계산
* Attention: Query·Key → softmax(scores) → weights @ Values

* Query = "지금 찾고 있는 정보", Key = "각 토큰의 특징", Value = "실제 담긴 정보"
* softmax로 관련도를 확률분포처럼 변환 후 Value를 가중합


* Next token 예측: score → softmax → argmax로 가장 확률 높은 다음 토큰 선택

</br>
