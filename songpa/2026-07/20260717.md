* 단원명 : LLM
* 학습 주제 : GPT

---


#### [학습 내용]

* 프롬프트 엔지니어링의 중요성을 학습했다.
    * 단순히 답변을 요구하는 프롬프트와, 핵심 조건을 먼저 정리하도록 유도하는 프롬프트를 비교했다.
    * 모델이 문제를 단계적으로 분석하도록 지시하면 더 논리적이고 일관된 답변을 생성할 수 있음을 실습했다.


* Function Calling의 동작 원리를 학습했다.
    * 사용자의 요청을 분석하여 적절한 함수를 선택하고(fake_model_decide_tool), 필요한 인자를 전달한 뒤, 함수 실행 결과를 다시 자연어 답변으로 변환하는 전체 흐름을 구현했다.
    * AI가 직접 모든 정보를 생성하는 것이 아니라, 필요한 경우 외부 함수나 시스템을 호출하여 결과를 활용할 수 있다는 개념을 이해했다.

</br>

#### [느낀 내용]

* 단순히 AI에게 질문하는 것보다 프롬프트를 어떻게 작성하느냐에 따라 결과의 품질이 크게 달라진다는 점이 인상적이었다. 특히 JSON 출력이나 단계적 사고 유도처럼 AI가 따라야 할 규칙을 명확하게 제시하면 원하는 결과를 훨씬 안정적으로 얻을 수 있었다.
* Function Calling을 통해 AI가 외부 기능과 연동되어 실제 서비스처럼 동작하는 과정을 보면서, LLM을 활용한 애플리케이션의 구조를 조금 더 구체적으로 이해할 수 있었다.


</br>

#### [활용 방안]

* 복잡한 문제를 해결할 때는 핵심 조건을 먼저 정리하도록 프롬프트를 설계하여 더 논리적인 답변을 유도한다.
* 실제 프로젝트에서는 Function Calling을 활용해 데이터 조회, API 호출, DB 검색 등의 기능을 AI와 연동하여 사용자 요청을 자동으로 처리하는 서비스를 구현해보고 싶다.
