* 단원명 : LLM
* 학습 주제 : GPT, LangChain

---

#### [학습 내용]

* OpenAI Tool Calling(Function Calling)을 실제 API와 함께 사용하는 방법을 학습했다.

  * `tools` 옵션에 함수의 이름, 설명, 파라미터(JSON Schema)를 등록하여 GPT가 필요한 함수를 직접 선택하도록 구현했다.
  * 모델이 반환한 `tool_calls`에서 함수명과 인자를 추출한 뒤 Python 함수를 실행하고, 실행 결과를 `tool` 메시지로 다시 GPT에게 전달하여 최종 자연어 응답을 생성하는 전체 흐름을 실습했다.
  * Tool Calling이 단순한 함수 호출이 아니라 LLM → Tool 선택 → 함수 실행 → 결과 전달 → 최종 답변 생성의 과정으로 이루어진다는 점을 이해했다.

* Fine-tuning의 기본 절차를 학습했다.

  * 학습 데이터를 JSONL 형식으로 준비하고 OpenAI Files API를 통해 업로드하는 과정을 실습했다.
  * 업로드한 파일을 이용해 Fine-tuning Job을 생성하고, 기본 모델(`gpt-4.1-mini`)을 사용자 데이터로 추가 학습시키는 과정을 확인했다.
  * Fine-tuning은 모델 자체를 새로 만드는 것이 아니라 특정 데이터에 맞게 응답 스타일이나 패턴을 학습시키는 방법이라는 점을 이해했다.

* Streamlit을 활용한 AI 챗봇 개발을 학습했다.

  * Streamlit을 이용해 간단한 웹 기반 AI 챗봇을 구현했다.
  * `st.session_state`를 활용하여 대화 내역을 저장하고 이전 대화를 유지하는 방법을 익혔다.
  * System Message를 통해 AI의 역할을 설정하고, 사용자와 AI의 메시지를 순차적으로 전달하여 대화형 서비스를 구현하는 방법을 실습했다.

</br>

#### [느낀 내용]

* LLM을 단순히 API로 호출하는 것에서 끝나는 것이 아니라, 외부 함수 호출, 모델 학습(Fine-tuning), 웹 서비스 구현까지 연결되는 전체 개발 흐름을 경험할 수 있었다.
* Tool Calling은 AI가 필요한 정보를 직접 판단하여 가져오는 방식이라 실제 서비스 개발에서 매우 활용도가 높을 것이라는 생각이 들었다.
* Streamlit을 사용하니 복잡한 프론트엔드 없이도 AI 서비스를 빠르게 구현할 수 있어 프로토타입 제작에 적합하다는 점을 알게 되었다.

</br>

#### [활용 방안]

* Tool Calling을 활용하여 DB 조회, API 호출, 파일 검색 등 외부 기능과 AI를 연동하는 서비스를 구현해보기
* Fine-tuning을 통해 특정 도메인이나 기업 데이터에 맞는 응답 스타일을 가진 AI 모델을 제작하는 프로젝트를 진행해보기
* Streamlit을 활용해 챗봇, 문서 요약기, 질의응답 시스템 등 AI 기반 웹 애플리케이션을 빠르게 프로토타이핑하기
